# 神力与设置

所有神力都在底部「外交大修」Tab 里，从左到右分四组：设置 | 附庸 | 战争 | 城镇管理。需要点两下的神力，选第一个目标后会在地图上画箭头、高亮区域；第二下点回第一个目标就取消。

## 附庸

| 神力 | 用法 | 效果 |
|---|---|---|
| 册封附庸 | 先点宗主，再点附庸 | 后者成为前者的附庸。宗主是附庸、或附庸有自己的附庸时不行 |
| 煽动独立 | 点一个附庸 | 它立即向宗主发动独立战争 |
| 大叛乱 | 点一个国家 | 立即爆发大叛乱，不看周期阶段 |
| 天命 | 点一个大国 | 王朝周期推进一个阶段，天命设到那个阶段的起点；衰落期再推就是大叛乱 |
| 分封附庸 | 点一座非首都城市 | 它自立为国，成为原国家的附庸 |

规则见[附庸](vassals.md)和[王朝周期与大叛乱](cycle.md)。

## 战争

| 神力 | 用法 | 效果 |
|---|---|---|
| 指挥军队 | 先点一支军队，再点目标 | 别国城市进攻，友方城市驻扎，空地扎营，点驻地解除 |
| 举国进攻 | 先点出兵的王国，再点目标城市 | 所有军队进攻别国城市，或全军前往友方城市驻扎 |
| 交还指挥 | 点一个国家 | 它所有听玩家命令的军队交还 AI |

不拿神力时也可以框选军队、右键下令。规则见[战争与军队](military.md)。

## 城镇管理

| 神力 | 用法 | 效果 |
|---|---|---|
| 移交城市 | 先点一座城，再点接收的王国 | 城市归接收方。首都不能移交 |
| 吞并王国 | 先点吞并方，再点被吞并方 | 被吞并方的城市全部归吞并方，它的附庸转给吞并方；吞并方本身是附庸时，这些附庸获得自由 |

两者都会立即更新双方的政体称号。

## 设置

点 Tab 最左边的设置按钮，打开模组自己的设置窗口（`SettingsWindow.cs`）。每个系统一个开关，按外交、内政、显示、性能分成几块，两列排开；点一下马上生效并存盘，「恢复默认」把所有开关打开。开关存在 NML 的 `ModConfig` 里，键名和分组见下表；改 `default_config.json`（新增、删除开关）要重启游戏才生效。

| 分块 | 开关 | 分组 / 键 | 默认 |
|---|---|---|---|
| 外交 | 分封与称臣 | `vd_group_vassal` / `vd_feudal_enabled` | 开 |
| | 和谈 | `vd_group_peace` / `vd_peace_enabled` | 开 |
| 内政 | 王朝周期 | `vd_group_cycle` / `vd_cycle_enabled` | 开 |
| | 政体随国力变化 | `vd_group_government` / `vd_gov_auto_enabled` | 开 |
| | 历史事件改制 | `vd_group_government` / `vd_gov_events_enabled` | 开 |
| 显示 | 国名显示政体 | `vd_group_government` / `vd_gov_name_enabled` | 开 |
| 性能 | 优化原版计算 | `vd_group_perf` / `vd_perf_enabled` | 开 |

# 政体

## 政体一览

每个国家有一个政体大类，**君主制**或**共和国**。显示出来的政体是一个王国特质（特质组「政体」），由大类、城市数、附庸状态决定：

| 大类 | 显示 | 条件 |
|---|---|---|
| 君主制 | 王国 | 5 座城及以下 |
| | 帝国 | 6 座城及以上 |
| 共和国 | 军事共和国 | 由将领夺权建立 |
| | 商人共和国 | 国家文化有「黄金法则」 |
| | 共和国 | 其余 |
| 附庸 | 公国 | 原本是君主制 |
| | 自治领 | 原本是共和国 |
| | 行省 | 整合度高的附庸，见[附庸](vassals.md) |
| | 世袭行省 | 整合度高、国王和宗主同一家族的附庸 |

成为附庸不改变大类，只改变称号，独立后自动恢复。成为行省时大类改为共和国，成为世袭行省时保留君主制。称号每年更新一次，成为附庸、获得独立、移交城市、吞并王国时立即更新。

国名后面接上政体，比如「科英布拉公国」，英文是「Duchy of Coimbra」，可以在设置里关掉。王国窗口和鼠标悬停提示的副标题显示政体，附庸接上宗主名（「公国 · 卡斯蒂利亚」），有王朝周期的接上阶段（「帝国 · 鼎盛」）。

### 领袖的称呼

领袖按显示的政体称呼，还没判定政体的国家按大类称国王或执政：

| 政体 | 称呼 |
|---|---|
| 王国 | 国王 |
| 帝国 | 皇帝 |
| 共和国、商人共和国、自治领 | 执政 |
| 军事共和国 | 护国公 |
| 公国 | 公爵 |
| 世袭行省 | 亲王 |
| 行省 | 总督 |

王国窗口、城市窗口的领袖一栏，王国、城市、单位的悬停提示，底部信息栏，选举与任命窗口都用这个称呼。原版写着「国王」的地方也换掉了：王国窗口的「在位(年)」「历代」两行和查看领袖的按钮，城市忠诚明细的「领导能力」「统治」，外交好感明细的「情绪」，以及新君即位、出走、逝世、被杀和当选、连任的世界日志。

### 手动设置

在原版特质编辑器里给国家换一个政体特质，改的是它背后的状态，称号之后仍按上表判定。选共和国一类的特质，大类变成共和国，选军事共和国还记为将领夺权建立；选王国、帝国，大类变成君主制。给附庸选行省或世袭行省，它就成为行省，整合度不到 90 的设为 95；选公国或自治领，它就退出行省，整合度 90 以上的设为 70。大类照自动成为这一档时的规则：公国、世袭行省是君主制，自治领、行省是共和国。手动改动在下一次每年判定时生效，和规则不符的部分同时纠正，比如给 2 座城的君主国选帝国，仍显示王国。

## 政体倾向

不同政体在开战、内政上各有倾向，按国家当前显示的政体取值（手动选的政体也算）。王国、帝国的开战行为和原版一致。

| 政体 | 停战期 | 敢挑的对手 | 其他 |
|---|---|---|---|
| 王国 | 5 年（原版） | 兵力不超过自己（原版） | — |
| 帝国 | 5 年（原版） | 兵力不超过自己（原版） | 威逼称臣的实力门槛从 3 倍降到 2 倍 |
| 共和国 | 10 年 | 兵力不超过自己 | 城市忠诚 +5（「共和之治」） |
| 商人共和国 | 15 年 | 兵力不到自己一半 | 城市忠诚 +5 |
| 军事共和国 | 2 年 | 兵力不超过自己的 1.25 倍 | 攻下的城不分封，自己吞 |
| 公国、自治领、行省 | — | — | 附庸不会自己开战 |

表里的停战期和敢挑的对手再乘上外交路线的倍数（和平主义、扩张主义），见[议会与政策](parliament.md#外交)。

- **停战期**：原版国家距离上一场战争要超过这么多年，才会考虑再开战。
- **敢挑的对手**：原版挑最近的、兵力不强于自己、关系不好的国家；这里双方兵力都按整个[阵营](vassals.md#集团)算，「不强于自己」换成上表的倍数，其余条件照原版。

按一场仗打 5 到 10 年估算，两场战争的间隔大约是：王国 11–16 年，共和国 16–21 年，商人共和国 21–26 年（还常找不到够弱的对手），军事共和国 8–13 年。

## 国家诞生时的政体

国家第一次被判定政体时掷一次大类。旧存档里已有的国家也这样补掷；身上已经有政体特质的不掷，按特质定大类。

原版一局里文化很少：文化只在没有文化的人建立第一座城时产生，新生儿和叛乱、分裂出来的国家都沿用原来的文化。所以文化只改变概率，同一个文化下的国家各掷各的。

| 国家文化的继承特质 | 是共和国的概率 |
|---|---|
| 外交晋升、黄金法则 | 50% |
| 名望之冠 | 25% |
| 其他 | 10% |

之后大类只由下面的历史事件和成为行省改变，不随文化变化。

## 共和国执政

共和国没有王室。

- **选举**：议会选出执政。现任执政一定参选；其余候选人是其他家族的城主，每个家族出分量最高的一位，按分量从高到低补满三位。分量是能力加声望：能力照原版挑领袖时看的，外交、武力、管理之和，父系文化的男性、母系文化的女性另加 999；声望是原版单位的声望，按 4 × √声望 计入（声望 25 算 20，100 算 40）。不掷骰子。每个氏族把全部议席投给立场离自己最近的候选人（两条轴上的直线距离，见[议会与政策](parliament.md#意识形态)），得票最多的当选，票数一样时排在前面的当选（现任，其次分量高的）。当选的城主离开城主之位、搬进首都。世界日志记一条，现任当选记「连任」。没有能参选的人（城主都没有家族、不在议会里）时，照原版挑能力最高的城主。
- **什么时候选**：执政没了时马上选；任期 12 年，满了就改选，现任当选就重新算任期。执政不是选上来的（比如玩家用神力换了人），从他上任时开始算任期。没有连任限制。
- **没有王室**：共和国的执政不会让自己的家族成为王室，城主也就不会偏向某个家族。
- **不会因绝嗣分裂**：共和国遇到原版的绝嗣分裂时，一律重新选举。

首都的议席归执政的家族，所以现任执政的家族在议会里本来就大，改选时占优势。

选举和任期是共和国本身的规则，关掉「历史事件改制」也照常运行。

## 选举与任命窗口

王国窗口左侧页签栏第三个（议会后面）是选举与任命，点开是单独的窗口。

- **共和国**：左边是执政选举。上面一行是现任执政和离改选还有几年；下面是三位候选人和各自的得票，议席半圆按候选人分块，右边一栏是预计当选的人；再下面是每个氏族投给谁，点一行在半圆里只亮这个氏族。预测按眼下的议会算，和真正改选用的是同一套规则。
  - **立即改选**：现在就按预测改选，任期重新算。
  - **指定执政**：先点一张候选人卡片，不经投票让他上任。
- **君主国**：左边是国王和继承顺位。继承顺位照原版挑继承人的方式：王室里能继位的人，按年龄和文化的继承特质排，第一位就是国王死后上台的人。本国的人后面接附庸里出身王室的国王（见[入继大统](#入继大统)），行里标出所在的附庸国。
- **封疆**：右边是国家的封疆图，每座城的领地按它的议席归属上色（首都归国王或执政的家族，其余归城主的家族），国外的陆地和水面各一种颜色，首都标王冠，其余的城标小方块。鼠标移到一块领地上，这个家族的领地都亮着、其他家族的压暗，左边的议席也只亮这个家族；点一下锁定这个家族，再点一次或点国外取消。下方上面是鼠标下的城（没有时是点过的城，其次是首都）的人口、议席和城主，下面是城主的家族占了几座城、共多少席。

## 历史事件

开关「历史事件改制」，默认打开。

除了下面的历史事件，议会也能改政体（要 3/4 的议席赞成），见[议会与政策](parliament.md#内政)。

### 入继大统

国王死后，本国王室里没有能继位的人时，附庸里出身王室的国王也能继承，比如分封宗室出去的子女。世袭行省、公国都算，只看附庸国王和宗主是不是同一个王室。几位候选照原版挑继承人的方式排（按年龄和文化的继承特质），第一位回宗主首都当国王，他的附庸国整个并入宗主。世界日志记一条。之后照原版处理，文化有「破碎王冠」时照常触发。附庸里也没有王室的人，才轮到原版的城主继位和下面的绝嗣。

### 王室绝嗣：君主国改制为共和国

原版里王室家族死绝、又找不到继承人时，多城国家会分崩离析，每个城主各自建国。现在君主国在这一刻有一定概率改由议会选举执政，改制为共和国，国家保住不分裂：

| 国家文化 | 改制概率 |
|---|---|
| 外交晋升、黄金法则 | 80% |
| 其他 | 40% |

没有改制的照原版分裂。世界日志记一条。

### 共和国称帝

条件：共和国、6 座城以上、不是附庸、处在王朝周期的鼎盛期。每年判定一次，概率是 0.5% 乘以执政的性格权重：

| 执政的特质 | 权重 |
|---|---|
| 基础 | 1 |
| 野心勃勃 | +3 |
| 嗜血、邪恶 | 各 +2 |
| 暴躁、偏执、弑君者、老兵 | 各 +1 |
| 知足、诚实、和平主义、温和（任意一个） | 权重为 0，不会称帝 |

鼎盛期一般约 55 年，算下来普通执政（权重 1）的共和国约 24% 会在鼎盛期称帝，执政野心勃勃（权重 4）时约 67%。

称帝后大类变成君主制，执政的家族成为王室（他没有家族就新建一个），国家显示为帝国。世界日志记一条。

### 乱世夺权

条件：国家处在王朝周期的崩溃期。每年有 10% 的概率发生，文化有「勇者晋升」的是 20%。

夺权的是国内杀敌最多的队长或士兵（国王除外）。结果看他的性格：

- **有野心**（野心勃勃、嗜血、邪恶、暴躁、偏执其中之一）：废掉原来的君主，自立为王，建立新王朝。大类变成君主制，他的家族成为王室（没有家族就新建一个），王朝周期回到新生。
- **没有野心**：将领们夺取政权，成立军事共和国，由他执政，之后按共和国的规则选举、换届。已经是军事共和国的，没有野心的将领不会再起事。

世界日志各记一条。

原版挂点：

- `DiplomacyHelpers.isWarNeeded`、`DiplomacyHelpers.getWarTarget`：停战期和敢挑的对手按政体取值（`AiTargets.cs`）。
- `KingdomBehCheckKing.execute`：共和国没有执政时由模组选举，不走原版的王室继承。
- `KingdomBehCheckKing.findKingFromRoyalClan`：本国王室找不到继承人时看附庸里的宗室（`Succession.cs`）。
- `KingdomBehCheckKing.checkKingdomChaos`：原版绝嗣分裂的入口，在这里改制或重新选举。
- `Kingdom.trySetRoyalClan`：共和国跳过，不立王室。
- `TooltipLibrary.showKingdom`、`KingdomWindow.showStatsRows`、`NameplateText`：国名和副标题。
- `StatsWindow.tryToShowActor`、`StatsRowsContainer.showStatRow`、`Tooltip.addLineText`、`TooltipLibrary.showActor`、`SelectedMetaUnitElement.show`、`LoyaltyAsset.getTranslationKey`、`OpinionAsset.getTranslationKey`：原版写死的「国王」换成领袖的称呼。原版的国王日志（`king_new`、`king_left`、`king_dead`、`king_killed`）换成模组的文案，见 `WorldLogs.Retitle`。

旧版的「城邦」已经取消，存档里的城邦特质在下一次判定时换掉。

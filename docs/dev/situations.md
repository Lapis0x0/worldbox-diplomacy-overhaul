# 局势

局势把原本藏在代码里的政治事件摆到台面上。议会负责固定议题的定期表决，局势处理表决解决不了的权力斗争，不提议案，也不改政策。

## 定义

每种局势是一个 `SituationDef`，继承[议题](parliament.md#表决) `Issue`，固定两档：左头结局在 −½，右头结局在 +½。

| 字段 | 含义 |
|---|---|
| `axis`、`load`、`lean` | 议题的政治轴、载荷和各家的处境，载荷取负数时翻转方向 |
| `years` | 基准时长：合力为 1 时走完全程的年数，默认 6；按月推进的局势是月数 |
| `monthly` | 按月推进：每个月所有国家一起推进一次（`Clock.Monthly`），每年的推进跳过它；大势收到的时长和窗口显示的都是月数 |
| `start` | 开局时的进度，默认 20 |
| `favor` | 对发起方的好感在态度里的权重，默认 0.5 |
| `enabled` | 局势还能不能进行：返回 false 时不开局，进行中的当月清掉。改制类的四个局势（兵变危机、王权旁落、帝制之议、王位空悬）填「历史事件改制」开关 |
| `trigger` | 每年判定是否开局；由事件开局的局势留空，由事件调用 `Situations.Start` |
| `actors` | 局势里的人（兵变的领头人，王权旁落的权臣和君主）的角色，`SetActor` 存成 `<id>_<角色>`，`ActorOf` 取（他死了或去了别国时是空），落幕或作废时一并清掉 |
| `initiator` | 开局时定下发起的势力，之后不变 |
| `outsider` | 发起方可以不在议会里：家族在本国没有议席时作为议会外的势力，议席为 0、自己不出推力，占主导的人和意识形态照议会的规则算；族人还在本国就一直算数 |
| `againstCrown` | 冲着朝廷来：掌权家族（王室，共和国是执政家族）是被冲着的一方，态度为 0、不出推力，合并集团时它的分也按 0 算，不会用自己的政见把同集团的盟友带向发起方；其他势力的态度把对发起方的好感换成减去对掌权家族的好感 |
| `onLeft`、`onRight` | 走到左头、右头时执行 |
| `desc` | 起因说明的语言 key，同一个局势有几种起因时按国家挑；留空是 `<id>_desc` |
| `leftOutcomes`、`rightOutcomes` | 一头有几种结局时填：每种结局有名字（语言 key 是它的 id，说明是 id + `_desc`）、分数和要执行的事，走到这一头时按分数比例抽一个，代替 `onLeft`、`onRight` |
| `moot` | 局势的前提已经不在：直接结束，不执行结局，也不记恩怨 |
| `fail` | 发起方已经输了：直接走到左头，照常执行结局、记恩怨 |
| `hold` | 这一次先不推进：进度不动，也不判定 `fail` 和结局。结局要的前提都写进 `moot`、`fail`、`hold`，结局本身只管执行，落幕记录写的就是实际发生的 |
| `drive` | 由别的系统驱动（王朝衰落）：每年调它，开局、进度和落幕都由它决定，不走推力公式 |
| `icon`、`leftIcon`、`rightIcon` | 局势的图标；落幕后结局行里走到的那一头的图标 |
| `pressures` | 大势：议会之外的因素，单位和推力相同，往右头推为正，可以随局势进行的时长变化（按月推进的是月数，其余是年数） |
| `stages` | 三个阶段各自的候选 |
| `pushes` | 各阶段抽中的候选带来的推力，默认 0.05、0.10、0.15 |

## 推进

进度从 0 到 100，每年在国家的结算月推进一次（`monthly` 的局势每月一次，下面的「每年」换成「每月」）：

```
政见得失 = 左头离理想位置的距离 − 右头离理想位置的距离
态度 = 政见得失 + 好感权重 × 对发起方的好感 ÷ 100 − 惯性 0.1，限制在 ±1
     （againstCrown：好感那一项换成 − 好感权重 × 对掌权家族的好感 ÷ 100）
推力 = 议席占比 × 态度
进度每年变化 = (各方推力之和 + 大势 + 抽中的候选) × 100 ÷ 基准时长
```

- 集团沿用议会的合并规则：成员取集团按议席加权的平均分。
- 发起方和它所在的集团态度固定为 1。
- 进度走到 0 是左头结局，走到 100 是右头结局。
- 附庸里的王位空悬、兵变危机、王权旁落另有一项大势「宗主」（`Situations.Overlord*`），力度最大 0.2 × 整合度 ÷ 100：
  - 兵变危机、王权旁落：宗主一般求稳，往左头拉，乘 (0.5 + 宗主对附庸的好感 ÷ 100)，限 −1 到 1。好感 +50 以上出全力，低于 −50 时反过来往右头推。
  - 王位空悬：宗主是君主国往新朝登基推，是共和国往改行共和推，不看好感。
- 发起的势力灭亡或失去全部议席时，局势走到左头，`onLeft` 收到的势力是空。`outsider` 的局势只看本国还有没有它的族人；宗室分支没有议会外的说法，没了议席就算不在了。
- `moot` 成立时局势直接结束，每年在推进之前判定；接着判定 `hold`，成立时这一次不推进；再判定 `fail`，成立时走到左头。
- 局势能进行的条件（`Situations.Available`）：议会开着、局势没有熔断、`enabled` 成立。不能进行时不开新局势，进行中的局势在下一个月直接结束，不执行结局；王位空悬随之不再拦着原版立王。

## 开局

由事件开局的局势调 `Situations.Start(国家, 局势, 准备, 开局后)`：不能进行或已经在进行时不开；准备函数挑出局势里的人存好，返回 false 就不开；开局后记世界日志。中途出错时清掉这次写下的数据，记到局势的熔断，不牵连调用它的政体系统。

## 阶段

进度 0–33、33–67、67–100 分成三个阶段，局势可以用 `stageEdges` 自定交界。每个阶段有若干候选，每个候选有名字、城市忠诚或军队伤害的修正，以及它是不是转机。

- 进入阶段时随机抽一个候选，只有抽中的生效，之前阶段抽中的效果继续保留。
- 退回上一阶段时摘掉刚退出那个阶段的效果，再次进入时重新抽。
- 抽中的坏事往右头推，转机往左头拉，力度由 `pushes` 决定。
- 一个国家有多场局势时，效果相加。
- 城市归心不计算局势带来的忠诚修正，避免衰落自我加速。

## 落幕

- 走到右头：反对的势力按态度记恨发起方，支持的势力对发起方记下恩情。
- 走到左头：发起方按态度记恨反对它的势力。
- 一头有几种结局时，记完恩怨按这一刻的局面算各结局的分数，抽一个执行：某个结局的概率 = 它的分数 ÷ 这一头分数之和，分数都不大于 0 时取第一个。分数由局面连续算出，不设门槛，局面变了概率跟着平滑地变。
- 先写落幕记录，再执行结局，执行完才清掉局势的数据：结局执行时局势里的人还取得到。

## 王朝衰落

特殊的局势，不走推力公式，由王朝周期驱动（`drive`）：每年在王朝周期之后，处在衰落期就开局或同步进度，离开衰落期时落幕。

| 定义 | 内容 |
|---|---|
| 进度条 | 天命，70（涨回来就中兴）在左头、20 在右头 |
| 阶段 | 式微 70–40、动荡 40–30、危亡 30–20，在进度条上占一半、四分之一、四分之一（`stageEdges` 0 / 50 / 75 / 100），每段内按天命均匀画。刚进衰落时天命不到 50，落在式微这段的后三分之一 |
| 两头 | 中兴（进入鼎盛）↔ 大叛乱（进入崩溃）；因不再是大国、关掉周期离开衰落的不记结局 |
| 大势 | 应得天命的组成：积弊、沉疴、城市归心、君主、附庸、民生、尾大不掉，基准 84 不显示 |
| 各方 | 对王室的向背计入应得天命，见[王朝周期](cycle.md) |
| 候选的力度 | 应得天命 ±2 / ±3 / ±4 |

| 阶段 | 坏事 | 坏事 | 转机 |
|---|---|---|---|
| 式微 | 人心浮动：城市忠诚 −20 | 军备废弛：军队伤害 −3% | 整饬吏治：城市忠诚 +10 |
| 动荡 | 民心思变：城市忠诚 −30 | 士气低落：军队伤害 −5% | 枕戈待旦：军队伤害 +5% |
| 危亡 | 人心离散：城市忠诚 −40 | 军无战心：军队伤害 −8% | 背水一战：军队伤害 +8% |

候选的效果叠加在衰落期原有的城市忠诚、附庸好感、军队伤害扣减之上。局势窗口的趋势行写天命和每年的变化（向应得天命靠拢一成），两边对垒的数值是应得天命里的分量，往上托的列在「维系王朝」。

窗口和开发命令 `sit` 的明细由 `Decline.Tally` 给出，和普通局势的 `SituationTally` 同形：大势、候选、各方是应得天命的分量，`total` 是天命每年的变化，用的是每年结算的同一个公式（`Cycle.Change`）。

## 兵变危机

领兵的队长拥兵逼宫。走到右头兵变才真正爆发，走到左头是危机化解。两条起因各掷各的，每年一次：

- **乱世**：在政体事件里掷（`Regime.TryMutiny`），崩溃期每年 10%（「勇者晋升」20%），全国杀敌最多的队长领头，见[乱世夺权](government.md#乱世夺权)。
- **欠饷**：禁军发完饷（`Guard.Pay`）还欠着时掷（`Mutiny.TryUnpaid`），概率是涣散程度 × 0.5（和每年逃散的比例相同，见[养兵](economy.md#养兵)），禁军编队里杀敌最多的队长领头。当年补清了积欠就不会闹。议会关着时欠饷不闹兵变。

| 定义 | 内容 |
|---|---|
| 领头的人 | 符合起因的队长里杀敌最多的（普通士兵不算），不是王室或宗室（共和国是执政家族）的人，他也会起事（已经是军事共和国时要有野心）。开局前记在 `vd_sit_mutiny_leader`。兵变靠的是他本人的威望：他死了或去了别国就是 `fail`，不由族人接手；兵被打散、不再是队长时局势继续，拥兵自重为 0 |
| `fail` | 他死了或去了别国；或者起事的由头没了（动机为 0：不在崩溃期，禁军也不欠饷），按分数多半抽到平息 |
| 发起方 | 他的家族（`outsider`、`againstCrown`）。他没有家族时开局前自立门户（原版建族，当场设为族长）；家族没有议席时作为议会外的势力 |
| 议题 | 分权 ↔ 集权，载荷 1。处境：占主导的人尚武 +0.3，离首都的远近 × −0.3，宗室 −1。王室不出推力 |
| 大势 | 拥兵自重：他带的军队占全国兵力（`countTotalWarriors`）的比例 × 动机，动机在崩溃期是 1（将领有野心），否则看禁军欠了几年的饷（涣散 ÷ (1 − 涣散)），欠满一年就是 1（欠饷闹事本意是讨饷，欠得越久越敢反）；朝纲崩坏：崩溃期 +0.2；迁延日久 −0.05 × 月数，不封顶 |
| 推进 | 按月（`monthly`），基准时长 4 个月，开局进度 20，一般几个月到一年见分晓 |
| 起因说明 | 欠饷的用 `vd_sit_mutiny_desc_unpaid`（禁军欠饷，聚众鼓噪），乱世的用 `vd_sit_mutiny_desc`（朝廷积弱，拥兵自重）；起因记在 `vd_sit_mutiny_unpaid`。开局的世界日志同样分两条 |
| `moot` | 发起家族成了王室、宗室或执政家族 |

两头各三种结局，按分数比例抽：

| 头 | 结局 | 分数 | 执行 |
|---|---|---|---|
| 危机化解 | 平息 | 1 − 涣散程度 | 不了了之，世界日志记一条 |
| 危机化解 | 弹压 | 反对兵变的各家推力占全部推力的比例 | 他被处死，他的家族记恨王室（`Resent` 1） |
| 危机化解 | 哗散 | 涣散程度 | 他带的那支军队连同他自己解甲回乡（`Guard.Discharge`），禁军和各城地方兵的积欠按散掉的人数勾销，和每年逃散一样 |
| 兵变爆发 | 夺位 | 他的兵权占比，崩溃期再加朝纲崩坏的 0.2 | 按[乱世夺权](government.md#乱世夺权)的性格规则：有野心自立新朝，没有野心成立军事共和国（已经是军事共和国时由他执政），世界日志记「将领们夺取政权」 |
| 兵变爆发 | 废立 | 支持兵变的各家（不算发起方）对王室的恶感（好感取负 ÷ 100，限 0–1）按议席平均；君主国王室里没有别人能继位时为 0 | 君主被处死，君主国由王室照原版另立新君，共和国重新选举 |
| 兵变爆发 | 索饷 | 涣散程度 | 拿首都仓库和君主自己的钱补发禁军积欠，先拿仓库，够了就停 |

不欠饷时（涣散为 0）索饷和哗散的分数为 0：乱世的危机化解时在平息和弹压之间抽，兵变爆发时多半是夺位，支持的各家对王室有恶感时也可能废立。既不在崩溃期也不欠饷时局势已经 `fail`，走不到兵变爆发。

| 阶段 | 坏事 | 坏事 | 转机 |
|---|---|---|---|
| 鼓噪 | 兵为将有：军队伤害 +5% | 骄兵悍将：城市忠诚 −10 | 朝廷犒军：城市忠诚 +10 |
| 跋扈 | 功高震主：城市忠诚 −20 | 军纪败坏：军队伤害 −5% | 诏令犹行：城市忠诚 +10 |
| 逼宫 | 禁军逼宫：城市忠诚 −40 | 甲士入城：军队伤害 +8% | 忠臣护驾：城市忠诚 +15 |

## 王权旁落

君主国的新君庸弱，一位权臣把持朝政。走到左头君主亲政，走到右头权柄易手。

| 定义 | 内容 |
|---|---|
| 开局 | 君主国照原版换了君主（不是开国，也不是经 `Regime.Install` 篡位、开新朝的，`Kingdom.setKing` 记下新君，见 `Hooks.cs`），在这个国家下一次结算的政体事件里掷一次：概率 = 庸弱程度 = (29 − 管理 − 智力) ÷ 29，限制在 0 到 1。29 是王朝周期里的平常君主（`Cycle.RulerMid`）。基准档的新君中位数 30，低的一成 22（24%），平均每次换君主约 3% |
| 权臣 | 议席最多的宗室分支和议席最多的外姓家族（不算宗室）里占主导的人（宗室分支是议席最多的那位王族城主，外姓家族一般是族长，见[议会与政策](parliament.md)），取原版威望（renown）高的。宗室分支的是摄政，否则是重臣专权；没有宗室分支的国家只有重臣专权。开局前记在 `vd_sit_regency_regent`，辅佐的君主记在 `vd_sit_regency_king`，是不是摄政记在 `vd_sit_regency_royal` |
| 发起方 | 权臣这一支（`outsider`、`againstCrown`）。宗室分支和王室是同一个原版家族，找发起方时跳过王室那一股：摄政出自宗室分支，自己的议席出推力，王室和它的盟友留在君主那边 |
| 议题 | 激进 ↔ 保守，载荷 1：保守的维护正统君主，激进的认实力不认名分。处境：占主导的人尚武 +0.3；外姓专权时宗室分支 −1 |
| 起因说明 | 摄政用 `vd_sit_regency_desc_royal`（新君庸弱，宗室摄政），否则用 `vd_sit_regency_desc`（新君庸弱，某家大权独揽） |
| 大势 | 野心勃勃：宗室摄政有野心（野心勃勃、嗜血、邪恶、暴躁、偏执之一，同乱世夺权）时 +0.3，外姓权臣不加；君主渐稳：−0.04 × 年数，不封顶。新君有多弱只决定开不开局，不再作为大势 |
| 推进 | 每年，基准时长 6 年，开局进度 20 |
| `moot` | 辅佐的君主不在位了（去世、被废），或者国家成了共和国 |
| `fail` | 权臣死了或去了别国 |

| 头 | 结局 | 分数 | 执行 |
|---|---|---|---|
| 亲政 | 还政 | 1 − 庸弱程度 | 权臣体面退场 |
| 亲政 | 罢黜 | 反对权臣的各家推力占全部推力的比例 | 权臣这一支（外姓家族或宗室分支）记恨王室（`Resent` 1） |
| 权柄易手 | 篡位 | 摄政时 1，否则 0 | 摄政即位，王室不变，不算改朝换代 |
| 权柄易手 | 王冠易手 | 外姓时 1，否则 0 | 权臣即位、他的家族成为王室，改朝换代（见[政权更替](government.md#政权更替)） |

| 阶段 | 坏事 | 坏事 | 转机 |
|---|---|---|---|
| 摄政 | 政出多门：城市忠诚 −10 | 朝野观望：军队伤害 −3% | 君臣相得：城市忠诚 +10 |
| 揽权 | 党羽遍布：城市忠诚 −20 | 宫廷戒严：军队伤害 +5% | 君主渐明：城市忠诚 +10 |
| 僭越 | 僭用仪仗：城市忠诚 −30 | 私兵入宫：军队伤害 +8% | 旧臣护主：城市忠诚 +15 |

## 帝制之议

鼎盛期的共和国每年掷称帝，掷中后开局，见[共和国称帝](government.md#共和国称帝)。

| 定义 | 内容 |
|---|---|
| 发起方 | 执政家族 |
| 议题 | 激进 ↔ 保守，载荷 −1：激进的维护共和，保守的拥护帝制。处境：执政家族 +1 |
| 大势 | 鼎盛期国运强盛 +0.12，走出鼎盛后盛极而衰 −0.2；众议纷纭 −0.035 × 已进行的年数，不封顶 |
| 基准时长、开局进度 | 6 年，20 |
| 左头 | 共和延续，执政家族占主导的人记一条世界日志 |
| 右头 | 执政加冕，规则同直接称帝 |

| `hold` | 执政刚死、还没选出继任时先不推进 |
| `fail` | 改选后执政不再出自发起家族 |

## 王位空悬

多城君主国王室绝嗣、附庸里也没有宗室入继，原版要分裂的那一刻开局，见[王室绝嗣](government.md#王室绝嗣君主国改制为共和国)。

| 定义 | 内容 |
|---|---|
| 发起方 | 议席最多、内部有占主导者的家族 |
| 议题 | 沿用政体议题的立场，方向相反（激进 ↔ 保守，载荷 −1，处境取政体议题的相反数）：无主时各家都有 +0.2 的轮流坐庄，折到这里往共和推 |
| 大势 | 议会代行：−0.03 × 已进行的年数（含当年），不封顶 |
| 基准时长、开局进度 | 6 年，50（没有现状可守，从正中开局） |
| 阶段 | 0–60 无主、60–80 角力、80–100 定局（`stageEdges`）：开局落在第一阶段，往登基那头走才升级 |
| 左头 | 改行共和，议会推举执政，规则同绝嗣改制；议会已经改了共和制时由下一次检查国王选举 |
| 右头 | 发起家族占主导的人登基，他的家族成为王室，改朝换代，世界日志记一条 |
| `moot` | 国家只剩一座城（照原版由城主继位），或者已经有了国王 |
| `fail` | 国家成了共和国，或者发起家族在本国已经没有能登基的人 |

局势期间 `Patch_CheckKing` 拦住原版另立国王，政体议案不能提出。无王时原版的国王忠诚加成为零，王朝周期的君主一项也随之走低。

| 角力 | 诸家角力：城市忠诚 −20 | 禁军观望：军队伤害 −5% | 公议渐成：城市忠诚 +10 |

## 调数

数值按这个目标调：多数局势 5–20 年收场（政变几个月到一年），几乎没有拖过 60 次推进的；哪头收场由国内力量对比决定，不一边倒。会拖下去的局势要有一项随时长增长、不封顶的大势（众议纷纭、议会代行、迁延日久），否则封顶的大势和抽中的候选会互相抵消，局势卡在中间。

`sit sim <局势 id> [次数] [each|unpaid]` 按每个国家眼下的议会推演：各方推力取开局时的值，大势按开局的情形（称帝在鼎盛期；王权旁落按开局时挑权臣、假定新君管理 + 智力 22；兵变默认按乱世，假定在崩溃期、不欠饷，`unpaid` 按欠饷，禁军的队长领头、欠一年饷、不在崩溃期），候选随机抽，统计两头的比例和推进次数；兵变另外按开局时的推力算两头各结局的概率。`each` 把每个不掌权的家族都当发起方算一遍。称帝只算够格的大国（连同附庸 6 座城以上、不是附庸）；兵变会给没有家族的领头人当场建族，推演完要重新读档。

基准档（`tamriel_910`，988 年，集团和恩怨已经积累起来）多是两三座城的小国，够格称帝的只有一个，所以称帝在几个合并出来的世界上看：`bench realms 6`、`bench realms 8`（基准档）、`bench realms 3`、`bench realms 4`（旧档 `tamriel_910.orig`）和 `tamriel_realms`，共 10 个够格的大国。

| 局势 | 右头 | 时长 p50 / p90 | 拖过 60 次推进 |
|---|---|---|---|
| 兵变危机 · 乱世（基准档推演） | 28% | 5 / 12 个月 | 0 |
| 兵变危机 · 欠饷（基准档实际 39 年，32 场） | 19% | — | 0 |
| 王权旁落（`tamriel_910` / `tamriel_realms` 推演） | 17% / 16%，看权臣一方的推力和野心：推力 0.57 时 71%，0.3 以下多半不成 | 21–22 / 28–29 年 | 0 |
| 帝制之议（10 个大国） | 约 35% | 10–27 / 26–36 年 | 0 |
| 王位空悬（基准档） | 63% | 8 / 31 年 | 0 |

称帝的成败看执政一方的推力：0.22 以下几乎不成，0.30 约三成，0.35–0.39 四成多，0.44 约八成，0.56 九成。王位空悬看国内格局，一家独大的国家多半登基，家族多而分散的大国改行共和：`tamriel_realms` 上 29%，基准档合并成 5 国时 54%，基准档本身小国多，63%。

推演里各方推力不变，实际局势中发起人的兵会折损、可能被任命为城主（不再是队长），国家走出鼎盛或崩溃后大势也会变，走势比推演更多变。

## 界面

- 图标 `ui/Icons/vd_situation`：红蓝两人背对背，中间一道闪电，草图和生成脚本在 `.art/situation/`。局势的世界日志都用它。开局和没有改变政权的结局（称帝的共和延续，兵变危机化解的平息、弹压、哗散）只记进世界历史；改变了政权或兵变爆发的结局在左上角弹出。
- 选中王国时，右下角议会按钮的上方是局势按钮，和议会按钮一样一直显示。悬停列出进行中的局势和当前阶段，阶段名按进度条上那一段的颜色；点击打开局势窗口。
- 局势窗口（`SituationWindow.cs`）也从王国窗口左侧页签栏打开，排在选举与任命后面，议会关闭时隐藏。
  - 标题是国名，下面一行政制名称，和议会窗口一样（`ParliamentWindow.RegimeLine`）。
  - 左边是局势卡片：进行中的在前，落幕 20 年内的调暗排在后面，写「N 年前」。
  - 右边依次是起因、进度条（按阶段从琥珀到红，走过的实色、没走到的压暗）、三个阶段的候选（抽中的点亮并写出效果，其余调暗、悬停看效果；候选总是三等分排，不跟进度条上阶段的宽窄）。窗口不显示各结局的概率，开发命令 `sit` 会打印。
  - 进行中的再加趋势行（进度、每年变化、约几年进入下一阶段或走到一头）和两边对垒：左右两栏对应两头，栏头是原版绸带写立场，各分大势和各方。王室第一、宗室第二、发起方第三，其余按推力排；同一个集团收成一行，悬停看成员；单股势力悬停看议席、政见得失和对发起方的好感。推力为零的列在底部的观望，王室除外。
  - 落幕的在趋势行的位置写走到的那一头和抽中的结局，一头只有一种结局时写这一头的说明。
  - 局势一年只变一次：打开窗口和数据指纹变了才算推力明细。
- 起因、结局说明用语言 key `<id>_desc`、`<id>_left_desc`、`<id>_right_desc`，`$clan$` 换成发起家族；栏头用 `<id>_side_left`、`<id>_side_right`。
- 共和国取局势的文案时，语言文件里有加了 `_republic` 后缀的 key 就用它（`Situations.Key`）：王朝衰落在共和国叫「国运衰微」，两栏是「维系国本 / 动摇国本」；兵变危机的废立说明是「处死执政，重新选举」。

| 文件 | 内容 |

语言 key 由局势 id 拼出：局势名 `<id>`，两头 `<id>_left`、`<id>_right`，阶段 `<id>_stage0` 到 `_stage2`；大势和候选的名字用它们自己的 id。

开发命令 `sit` 列出进行中的局势和推力明细，也能开局、拨进度、直接结算、单独推进一个国家，见 `Dev.cs` 顶部。

`kingdom.data` 里的键：

| 键 | 含义 |
|---|---|
| `<局势 id>_progress` | 进度，进行中的局势才有 |
| `<局势 id>_since` | 开局的年份 |
| `<局势 id>_by` | 发起势力的 `ParliamentClan.Key` |
| `<局势 id>_pick0` 到 `_pick2` | 各阶段抽中的候选下标 |
| `<局势 id>_end_year`、`_end_since`、`_end_right`、`_end_by`、`_end_outcome`、`_end_pick0` 到 `_end_pick2` | 最近一次落幕：年份、开局年份、是否走到右头、发起家族的名字、抽中的结局（一头只有一种结局时 −1）、各阶段抽中的候选；20 年后清掉 |
| `vd_sit_loyalty` | 全部局势的城市忠诚修正之和 |
| `vd_sit_damage` | 全部局势的军队伤害百分比之和 |

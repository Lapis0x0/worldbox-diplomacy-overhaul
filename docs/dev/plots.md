# 密谋与动机

## 原版的密谋

原版国王（以及城主、家族成员）大约每 1–1.5 年考虑一次密谋：把所有当前可行的密谋放进一个池子，打乱后挑一个发起。

- **能不能做**：等级、个人和王国声望、智力外交军事管理四项属性（默认都要 ≥ 2）、身份、金币（国王发起时看国库，见[国库与军饷](economy.md)），再加每个密谋自己的条件。
- **没有家族的人不考虑密谋。**
- **进度**：发起人每隔几秒推进一次，每次加「智力 + 1」，普通密谋满 60 就执行，一般不到一年。
- **没有失败**：做完就执行。条件不再满足、发起人死亡或太久没推进时中止。

国王能做的原版密谋大多要求 5 级以上，而国王多在 3 级上下，所以国王考虑密谋时池子大多是空的，或者只有一两个。

## 动机

模组的密谋除了条件，还有**动机**：条件决定能不能做，动机决定有多想做。

国王每次考虑密谋时，以 `动机 ÷ (动机 + 1)` 的概率把这个密谋放进池子：动机 1 是 50%，动机 3 是 75%，动机 0 时不考虑。放进池子后和其他密谋一起随机挑。动机只影响发不发起，密谋开始后只看条件；在原版密谋编辑器里强制发起时不看动机。

**动机 = 局势 × 性格。**

### 性格

用原版的性格（管理型、军事型、外交型、平衡型、狂人）。每个密谋看一项性格数值（好战、治理、外交），系数是 `0.5 + 2 × 数值`：主导这一项的性格 ×1.5，其余 ×0.6–0.9。

- 野心勃勃：争权类密谋（独立、威逼称臣）×1.5
- 知足：所有密谋 ×0.5
- 狂人：每次考虑时动机再乘以 0–2 之间的随机数

### 各密谋的动机

| 密谋 | 局势 | 性格 |
|---|---|---|
| 独立 | 怨恨：好感低于设置值（默认 0）时开始，每再低 50 点 +1，最多 2；再乘以 `1.2 - 整合度/100`；宗主是某场战争的主攻方或主守方时，再乘以 `1 + (1 - 整合度/50)`（整合度 50 以上不变）；臣属方针是争取自治 ×1.5、忠诚臣属 ×0.5 | 好战，争权 |
| 威逼称臣 | 实力差距：刚够门槛是 0.3，每多一倍门槛 +1，最多 2 | 好战与外交的平均，争权 |
| 和谈 | 领先方：战果差距达到期望时为 2，否则为 0。落后方：落后的战果 ÷ 40 × 战争年数 ÷ 5，最多 2 | 领先方不看性格；落后方看外交 |
| 中兴 | 危机感：(60 − 天命) ÷ 20，在 0 到 2 之间 | 治理 |
| 分封宗室 | 超出治理上限：每超出一座 +0.5，最多 2；领地制度是分封制 ×2，中央直辖 ×0.5 | 治理 |
| 收归直辖 | 离治理上限的余量：每空一座 +0.5，最多 2；领地制度是中央直辖 ×2，分封制 ×0.5 | 治理 |

密谋的条件和效果见[附庸](vassals.md)、[王朝周期](cycle.md)和[和谈](peace.md)，领地制度、臣属方针见[议会与政策](parliament.md)。

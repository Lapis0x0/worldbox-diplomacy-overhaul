# 附庸

## 关系

附庸关系只记在附庸国一方：`kingdom.data` 的 `vd_overlord_id` 存宗主的 id。宗主灭亡时它的附庸全部自由；宗主 id 失效时下次读取就清掉。

**不允许附庸链**：宗主自己不能是附庸，有附庸的国家不能成为别人的附庸。

成为附庸的那一刻：

1. 两国之间的战争结束。两国是同一场战争的主攻方和主守方时，这场战争以和平结束；否则附庸退出那场战争。
2. 附庸退出原来的联盟。
3. 更新政体称号（君主制变公国，共和国变自治领，见[政体](government.md)）。
4. 附庸的战争状态和宗主对齐（见下文）。

## 集团

宗主和它的所有附庸算一个**集团**。

集团再加上宗主的联盟算一个**阵营**：宗主有联盟时，阵营是联盟的所有成员和成员的附庸；没有联盟时，阵营就是这个集团。

- 原版 AI 挑战争目标、挑结盟对象时，跳过同阵营的国家，所以盟友不会去打宗主的附庸。
- AI 挑战争目标时，双方兵力都按整个阵营算（原版只算联盟）。附庸挨打时宗主和宗主的盟友都会来救，想打附庸的国家要掂量整个阵营。
- 附庸不会自己发动战争，不能发起结盟、加入联盟，也不会被选为结盟对象。
- 王国窗口显示「宗主」或「附庸」一栏，标题写成「政体 · 宗主名」。
- 王国地图上，附庸的边界线用宗主的颜色，填充保持自己的颜色；行省的填充也用宗主的颜色，看上去是宗主版图的一部分，和宗主之间仍有边界线。
- 联盟地图按阵营显示：染色、名牌、悬停高亮、悬停提示和点击都按阵营；附庸不单独显示名牌，联盟名牌挂在视野内最强的成员或附庸首都上。名牌上的人口、悬停提示里的人口和兵力都算整个阵营；没有联盟的集团显示宗主的王国提示，人口和兵力也换成整个集团的。

### 战争同进同退

- 宗主加入一场战争的防守方，它的附庸全部加入防守方。宗主加入攻方时，每个附庸按整合度的百分比概率参战（最低 30%，行省一定参战），每场战争只掷一次。
- 附庸被攻击，宗主加入防守方。
- 宗主退出一场战争（议和、战败），附庸以同样的方式退出。
- 附庸只参加宗主参加的战争：大约每个游戏月同步一次，附庸不在宗主那一边的战争会被移出，宗主的战争按上面的规则补进去。
- 总体战不受以上规则约束。

**背叛**：宗主和附庸出现在同一场战争的对立两边（神力宣战、玩家下令进攻自己的集团），附庸关系立即解除。

## 整合度与行省

每个附庸有一个 0–100 的整合度，表示它在自立和归化之间的位置。涨到 90 成为**行省**或**世袭行省**，跌到 50 以下退回自治领或公国。成为和不再是行省时，世界日志各记一条。

整合度不显示数字，所在的档次显示为一个王国特质（特质组「整合度」），只有附庸有：

| 整合度 | 特质 |
|---|---|
| 0–30 | 积怨 |
| 30–50 | 离心 |
| 50–90 | 归附 |
| 90–100 | 一体 |

鼠标悬停在这个特质上，提示里显示整合度的具体数字。在特质编辑器里换成另一档，整合度就设到那一档的中间值（15、40、70、95），之后照常变动。

### 起点

| 成为附庸的途径 | 起点 |
|---|---|
| 分封宗室、攻城改分封、神力分封附庸 | 95（一出来就是行省） |
| 叛乱改分封 | 70 |
| 威逼称臣、神力册封附庸 | 35 |
| 投降、独立战争失败重新成为附庸 | 0 |
| 和谈中被败方让出 | 35 |

附庸随被吞并的宗主转给吞并方时，整合度不变。装模组前就有的附庸从 35 开始。

### 每年的变动

宗主的周期阶段决定方向，两国的结构因素决定快慢：

| 因素 | 每年 |
|---|---|
| 宗主处在新生或鼎盛 | +1 |
| 宗主没有周期（设置里关掉了） | 0 |
| 宗主处在衰落 | -3，天命每低于 50 五点再 -1（天命 30 时 -7） |
| 宗主处在崩溃 | 衰落的值再 -1 |
| 和宗主的城市接壤 | +1；不接壤 -1 |
| 和宗主同一个文化 | +1 |
| 和宗主同一个宗教 | +1 |
| 和宗主不是同一个物种 | -1 |
| 两国国王出自同一家族 | +1 |
| 城市数达到宗主的一半以上 | -1 |
| 宗主自己不到 6 座城 | 每少一座 -1 |
| 宗主的附庸政策是自治特许 | -1 |
| 附庸的臣属方针：争取自治 / 忠诚臣属 | -1 / +1 |

整合度低于 30 时，上升的速度减半。

宗主一方赢下一场战争，参战的附庸 +5；宗主一方战败，它的所有附庸 -5。议和不变。附庸打下的城被宗主拿走或分给别人，每座 -3，见[攻城改分封](#分封)。

盛世里接壤、同文化的附庸每年 +3：叛乱改分封的约 7 年成为行省，威逼称臣的约 18 年，投降的约 40 年。宗主刚进衰落时，这样的行省每年 0，天命跌到 30 时每年 -4，十年左右退回自治领或公国；隔海、异族的掉得更快。

### 行省

成为行省的那一刻，看附庸的国王和宗主的国王是不是出自同一家族：

- **世袭行省**：同一家族，比如分封宗室出去的封国。保留君主制和王室，照常世袭，称号比如「科英布拉世袭行省 · 卡斯蒂利亚」。
- **行省**：其他情况。政体大类改为共和国，按共和国的规则由议会选举执政、12 年任期，不立王室；在位的君主从这时开始算任期。称号比如「科英布拉行省 · 卡斯蒂利亚」。

世袭行省每年检查一次：统治家族和宗主的王室（宗主是共和国时看执政的家族）不再一致，比如宗主改朝换代、世袭行省自己绝嗣，就改成普通行省，政体改为共和国，世界日志记一条。哪一方王位空着时不检查。普通行省不会变回世袭行省。

两种行省除了政体和称号，其他规则完全一样：一定跟着宗主参战、大叛乱时很少造反、可以被收归直辖、地图上用宗主的颜色。

- 退回附庸时，世袭行省显示为公国，行省显示为自治领；独立后按各自的政体。
- 在特质编辑器里给附庸选行省、世袭行省，它就成为行省；选公国、自治领，它就退出行省，见[政体](government.md#手动设置)。

### 收归直辖

不是附庸、也不在衰落或崩溃期的国家，城市数还没到原版的治理上限时，国王（共和国是执政）可以发起「收归直辖」密谋（等级至少 4，金币至少 30），条件是它有行省。离上限越远越想发起，治理型的国王更积极，见[密谋与动机](plots.md)。

- 选哪个行省：接壤的优先，其次整合度高的。
- 收几座：离上限空几座收几座，最多 3 座。一座一座收：先收和行省首都不相连的飞地，再收和宗主接壤、收走后不会把行省切断的城，同一档里离宗主首都近的优先，行省的首都最后收。
- 空位够把行省剩下的城全部收下时，整个行省并入宗主，行省消失；否则行省少了几座城，仍是行省，等下次有空位再收。
- 世界日志记一条。

收回的城不会让宗主超出上限，所以不会刚收回来又被分封宗室分出去。和分封宗室一起，宗主的直辖版图会围着治理上限来回调整：超了分封出去，空了从行省收回来。

### 辖区调整

每年，宗主和它的行省之间整理一次版图。一座城不是首都、和自己国家的首都不相连，相邻的城一半以上属于另一方（宗主或它的某个行省），就有 20% 的概率划给那一方。宗主的飞地划给包围它的行省，行省的飞地收归宗主。公国、自治领不参与。

## 好感

附庸对宗主有这几条好感修正，在原版好感明细里能看到：

- **效忠宗主**：+30。
- **宗主国运**：看宗主的王朝周期，新生 +10，鼎盛 +20，衰落和崩溃期 -10，天命每低于 50 一点再 -3，最低 -90。
- **宗主势微**：宗主自己不到 6 座城时，每少一座 -10。
- **共同敌人**（原版，+50）：附庸被拖进宗主的仗不算，只有附庸自己挨打、宗主来救的那场战争才算。
- **自治特许**、**强制同化**：宗主的附庸政策，见[议会与政策](parliament.md#外交)。
- **附庸贡赋**：宗主收的贡赋越重，附庸越不满，见[议会与政策](parliament.md#外交)。

## 成为附庸的途径

### 投降

和谈谈到称臣档时，败方成为胜方的附庸；胜方本身是附庸时，败方成为胜方宗主的附庸。败方原有的附庸，和胜方集团接壤的有一定概率归胜方，其余独立。和谈谈到让出附庸档时，败方也会交出一部分附庸。规则见[和谈](peace.md)。

### 分封

开关在设置里（默认打开）。宗主自己是附庸时不会分封。下面的概率是领地制度为「有限分封」时的，「分封制」×1.5，「中央直辖」×0.5，见[议会与政策](parliament.md#内政)。

**叛乱改分封**：原版里密谋叛乱成功，城主会带着城市自立并开战。现在宗主有一定概率把这座城分封出去，换来附庸而不是敌人：

| 宗主的周期阶段 | 分封概率 |
|---|---|
| 鼎盛 | 80% |
| 没有周期或新生 | 50% |
| 衰落 | 20% |
| 崩溃 | 0 |

首都和与首都相邻的城市不会被分封。分封出去的国家由发起密谋的人统治，参与密谋的其他城市（首都除外）只要和起事的城一座接一座连着，就一起归入新国家；不相连的留给宗主。

**攻城改分封**：攻下一座城、正要并入时，如果攻方已经达到原版的治理城市上限，有 75% 的概率不并入而是分封出去：

- 有和这座城接壤、不到 3 座城的附庸：并给接壤城市最多的那个。
- 否则城里第一个成年、不是国王的居民建国，成为攻方的附庸。城里没人时归攻方。
- 攻下的是同集团的城不会分封。
- 军事共和国攻下的城不分封，照原版并入。

**附庸打下的城**：附庸随宗主出征，靠打仗最多长到 3 座城。

- 这座城和附庸领土接壤、附庸不到 3 座城：照原版归附庸。
- 否则（附庸已有 3 座及以上，或这座城是隔着别国的飞地）：宗主没到治理上限、并且和这座城接壤，就归宗主；不然按上面的规则并给附近不到 3 座城的附庸，或另封新附庸，城里没人时归宗主。
- 已经超过 3 座城的附庸不会被拿走城市，只是不再靠打仗扩张。
- 打下的城最后没留给附庸自己（归了宗主、别的附庸或新封的附庸），这个附庸整合度 -3。

### 威逼称臣

强国的国王可以发起「威逼称臣」密谋（等级至少 4，花费 30 金币，王国声望至少 50，需要外交能力），遣使威逼一个接壤的弱小邻国。国王有多想发起，看实力差距和他的性格，见[密谋与动机](plots.md)；玩家可以在原版的密谋编辑器里让国王强制发起。

发起条件：

- 强国不是附庸，不处在衰落或崩溃期。设置里关掉分封时这个密谋也一起关掉。
- 至少有一个接壤的邻国愿意称臣：还有城市；不是附庸，也没有附庸；没在和强国打仗；强国和它的附庸加起来的实力，至少是对方整个[阵营](#集团)的 3 倍（帝国是 2 倍），所以有盟友撑腰的国家不容易被吓住，同一联盟的国家也不会互相逼迫称臣；它对强国的好感不低于 0。

有多个邻国满足条件时，选离得最近的那个。密谋期间条件一直要成立，否则密谋中止。密谋完成后对方成为附庸，世界日志记一条。

### 分封宗室

君主国的国王可以发起「分封宗室」密谋（等级至少 4，金币至少 30）。条件：

- 国家不是附庸，是君主制，城市数超过原版的治理上限。设置里关掉分封时这个密谋也一起关掉。
- 国王家族里有成年、不是国王、住在本国的成员，国王的子女优先。

超出上限越多越想发起，治理型的国王更积极，见[密谋与动机](plots.md)。

密谋完成后，离首都最远的城和与它相连的城（由远及近，超出几座分几座，最多 3 座；首都和与首都相邻的城不分）归这位宗室，他当国王，新国家是君主制、成为附庸，整合度从 95 开始，是世袭行省。世界日志记一条。

### 神力

- **册封附庸**：先点宗主，再点附庸。
- **分封附庸**：点一座非首都城市，它自立为国、成为原国家的附庸。国家至少要有两座城；城主当国王，没有城主就随机一个居民；原国家本身是附庸时，新国家成为原国家宗主的附庸。

## 独立

### 独立密谋

附庸的国王可以发起「独立密谋」（等级至少 3，花费 20 金币，需要外交能力），玩家也可以在密谋编辑器里让附庸的国王强制发起。条件：

- 宗主处在衰落或崩溃期，或者宗主实力低于附庸实力的 120% 乘以 `1 - 整合度/200`：整合度 0 时是 120%，行省大约是 60%。

附庸有多想发起，看它对宗主的怨恨和国王的性格：好感低于 0 才开始怨恨，越低越想反，整合度越低越记恨；宗主亲自打仗时，整合度低于 50 的附庸更想趁机起兵，见[密谋与动机](plots.md)。

密谋成功后，附庸脱离宗主，向它发动一场普通战争（独立战争）。宣战失败时恢复附庸关系。

发动独立战争的附庸同时退出它随宗主参加的战争，不再与宗主的敌人为敌；它自己是主攻方或主守方的战争照打。

### 独立战争的结局

独立战争结束时：宗主一方获胜，叛乱方重新成为附庸（宗主已经成了别人的附庸、或叛乱方有了自己的附庸时除外）；其他结局，叛乱方彻底独立。

神力**煽动独立**直接让附庸发动独立战争，结局规则相同。大叛乱也会让附庸按整合度的概率发动独立战争，见[王朝周期与大叛乱](cycle.md)。

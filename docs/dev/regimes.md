# 政制名称

议会窗口国名下面的一行小字，按国家现行的政策组合起名，悬停列出构成这个名字的各项政策的现行选项。议会关掉时不显示。

名字在语言文件里，key 是 `vd_regime_<id>_monarchy` 和 `vd_regime_<id>_republic`，没有这个 key 就是「—」。第一次起名时检查一遍：后面一条的范围被前面一条包含、条件比前面那条严，而两条同一政体都有名字，后面这条就永远轮不到，在日志里警告。开发命令 `parl regime` 列出每个名字有几个国家在用。

议会窗口左边那一栏的标题按政制换叫法，key 是名字的 key 加 `_assembly`（如 `vd_regime_celestial_monarchy_assembly`），没配的叫议会：

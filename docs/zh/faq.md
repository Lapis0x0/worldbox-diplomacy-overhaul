# 常见问题

**帝国为什么开始衰落？**

每个王朝都会积累积弊，晚期衰老加快，再好的王朝也会走向衰落。战败、丢城、君主能力差和附庸整合度下降都会加快衰落。可以多打胜仗，或等待君主发起中兴。见[王朝兴衰](cycle.md)。

**为什么各地城市接连叛乱？**

王朝衰落时，天命越低，城市忠诚度下降越多，忠诚度最低的城市最先叛乱。议会推行的政策偏离某个家族的立场（政见不合），或把兵和钱收归中央（削藩），该家族的城市也会不满。城市的忠诚度明细可以查看原因。见[议会与政策](parliament.md#地方的不满)。

**附庸为什么独立了？**

附庸对宗主好感低，并且宗主不足以压制它时，附庸会发起独立密谋。宗主衰落、附庸积怨深、宗主在别处作战、附庸贡赋过重，都会促成这一点。可以查看附庸的好感明细和整合度特质。见[附庸](vassals.md#独立)。

**国家为什么把刚攻下的城市分封了？**

国家的城市数超过原版的治理上限后，新攻下的城市多数会分封为附庸，而不是并入本国。在议会中推行「中央直辖」可以减少分封。见[附庸](vassals.md#附庸从哪来)。

**军队为什么不出击？**

兵制不是贵族私兵时，地方军以守卫边境为主，兵力不少于敌城守军时才会出击，出征主要由禁军承担。另外，欠饷的城市和国家不征召新兵。可以直接给军队下令，见[指挥军队](commands.md)。

**军队为什么越来越少？**

可能是欠饷。国库或城市仓库发不出军饷时，每年有一部分士兵退伍，其余士兵的伤害也会下降。王国窗口和城市窗口会显示欠饷。见[国库、军饷与营建](treasury.md)。

**战争为什么长期不结束？**

开战满 3 年后才能和谈。领先方的战果没有达到期望时会拒绝，好战的国王期望较高，但战争越久、伤亡越多，期望越低。总体战不参与和谈。见[战争与和谈](war.md)。

**大城为什么攻不下来？**

原版中城里只要还有一个守方单位，攻城进度就停在 5%。现在攻方队长会主动清剿守方单位，攻方人数达到守方的 5 倍时可以直接破城。见[战争与和谈](war.md#攻城)。

**共和国为什么变成了帝国？**

处于鼎盛期的大型共和国，有野心的执政可能自立为帝。可以在设置中关闭「历史事件改制」。见[政体与领袖](government.md#共和国称帝)。

**进攻命令为什么在读档后消失了？**

进攻命令不进入存档，读档后军队恢复原来的行为。驻扎和扎营会保存。

**旧存档能用吗？**

可以。装载模组之前的存档能直接读取，缺少的数据会在游戏中自动补齐：政体按文化决定，够大的国家直接视为鼎盛，已有的附庸从离心档开始。

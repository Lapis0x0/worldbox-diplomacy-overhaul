# 常见问题

**我的帝国好好的，怎么突然开始衰落了？**

每个王朝都会积累积弊，越到晚年老得越快，再好的王朝也会走下坡路。打输仗、丢城、君主昏庸、附庸离心都会加快衰落。想撑住，就要多打胜仗，或者等一位 5 级的雄主发起中兴。见[王朝兴衰](cycle.md)。

**为什么各地城市接二连三地造反？**

王朝衰落时，天命越低，城市忠诚扣得越多，忠诚最低的城会先造反。另外，议会推行的政策离某个家族的立场太远（「政见不合」），或者把兵和钱收归中央（「削藩」），这个家族的城也会不满。打开城市的忠诚明细就能看到原因。见[议会与政策](parliament.md#地方的不满)。

**附庸为什么突然独立了？**

附庸对宗主不满，又觉得宗主压不住它时就会密谋独立。宗主衰落、附庸积怨深、宗主在别处打仗、宗主收的贡赋太重，都会让附庸起兵。看附庸的好感明细和它的整合度特质。见[附庸](vassals.md#独立)。

**大国为什么把刚打下的城封给别人了？**

国家的城市超过原版的治理上限，新打下的城多半会分封成附庸，而不是自己吞下。想让国家少分封，可以在议会里推行「中央直辖」。见[附庸](vassals.md#附庸从哪来)。

**为什么我的军队不出击？**

兵制不是贵族私兵时，地方军以守边为主，只有兵力不少于敌城守军时才会出击；出征主要靠禁军。另外，欠饷的城市和国家不征新兵。想让某支军队去打，直接给它下令，见[指挥军队](commands.md)。

**为什么军队越打越少？**

可能是欠饷。国库或城市仓库发不出军饷时，每年有一部分士兵解甲归田，剩下的伤害也会下降。看王国窗口和城市窗口里的欠饷提示。见[国库与军饷](treasury.md)。

**战争打了好多年都不结束？**

开战满 3 年后才能和谈。领先方的期望比战果高时会拒绝，好战的国王非要打到对方称臣不可，但打得越久、死的人越多，期望会越来越低。总体战不和谈。见[战争与和谈](war.md)。

**大城怎么也打不下来？**

原版里城里只要还有一个守军，进度就卡在 5%。现在攻方队长会主动去清剿守军，攻方人数达到守方 5 倍时可以直接破城。兵力不够多的话，还是要先把守军清掉。

**共和国怎么变成帝国了？**

鼎盛的大共和国，有野心的执政可能自立为帝。不想看到这类事件，可以在设置里关掉「政体随历史事件改变」。见[政体与领袖](government.md#共和国称帝)。

**我下的进攻命令读档后没了？**

进攻命令不进存档，读档后军队回到原来的行为。驻扎和扎营会保存。

**旧存档能用吗？**

能。装模组之前的存档可以直接读，模组需要的数据会在游戏里自动补上：政体按文化掷一次，大国直接算鼎盛，已有的附庸从离心开始。

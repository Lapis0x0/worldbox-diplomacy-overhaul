# 密谋

原版的国王大约每一两年考虑一次密谋：把当前能做的密谋放在一起，随机挑一个。原版国王能做的密谋大多要 5 级以上，所以大多数时候什么也不做。

模组新增了几个密谋，并且给每个密谋加了**动机**：条件决定能不能做，动机决定有多想做。局势越紧迫、国王的性格越合适，越可能发起。在原版的密谋编辑器里可以让国王强制发起，不看动机。

## 新增的密谋

| 密谋 | 谁发起 | 什么时候想做 | 偏爱它的性格 |
|---|---|---|---|
| 独立密谋 | 附庸的国王 | 对宗主越不满越想做；宗主在别处打大仗时更想 | 好战，有野心 |
| 威逼称臣 | 强国的国王 | 比邻国强得越多越想做 | 好战或擅长外交，有野心 |
| 和谈 | 交战双方的国王 | 领先方战果够了就想谈；落后方输得越多、打得越久越想谈 | 落后方擅长外交 |
| 中兴 | 衰落王朝的君主 | 天命越低越想做 | 擅长治国 |
| 分封宗室 | 君主国的国王 | 城市超出治理上限越多越想做 | 擅长治国 |
| 收归直辖 | 有行省的宗主 | 离治理上限越远越想做 | 擅长治国 |

- 知足的国王什么密谋都不太想做，野心勃勃的更想独立、逼人称臣。
- 议会的政策也会影响动机：领地制度是分封制时更想分封宗室，中央直辖时更想收归直辖；附庸的臣属方针是争取自治时更想独立。
- 国王发起密谋花的是国库的钱。
- 原版的「和平谈判」密谋被和谈取代。

每个密谋的具体条件和结果见[附庸](vassals.md)、[王朝兴衰](cycle.md)和[战争与和谈](war.md)。

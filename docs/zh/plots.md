# 密谋

密谋是国王、城主和家族成员发起的长期行动，完成后执行结果。原版的国王大约每一两年考虑一次密谋，从当前能做的密谋中随机挑一个。原版国王能做的密谋大多要求 5 级以上，所以大多数时候什么也不做。

模组新增了若干密谋，并为每个密谋加入**动机**：条件决定能不能做，动机决定有多想做。局势越紧迫、国王的性格越合适，越容易发起。在原版的密谋编辑器里可以强制发起密谋，不受动机限制。国王发起密谋的花费从国库支出。

城主的叛乱密谋在城市重新安定后会自行中止。君主驾崩或执政出缺时各城忠诚度骤降，这期间立起的叛乱密谋，多数会在新君或新执政上任、忠诚度回升后中止。强制发起的叛乱密谋不受影响。

## 新增的密谋

| 密谋 | 发起者 | 动机来源 | 偏爱的性格 |
|---|---|---|---|
| 独立密谋 | 附庸的国王 | 对宗主越不满越强；宗主在别处作战时更强 | 好战，有野心 |
| 威逼称臣 | 强国的国王 | 比邻国强得越多越强 | 好战或擅长外交，有野心 |
| 和谈 | 交战双方的国王 | 领先方战果足够时；落后方战败越多、战争越久越强 | 落后方擅长外交 |
| 中兴 | 衰落王朝的君主 | 天命越低越强 | 擅长治国 |
| 分封宗室 | 君主国的国王 | 城市超出治理上限越多越强 | 擅长治国 |
| 收归直辖 | 有行省的宗主 | 离治理上限越远越强 | 擅长治国 |
| 拉拢 | 族长 | 目标越接近加入集团越强；自家势单力薄时更强 | 擅长外交，有野心 |
| 脱离集团 | 集团中魁首以外的族长 | 对集团越不满越强 | 暴躁，有野心 |

- 知足的国王对所有密谋都不积极，有野心的国王更倾向于独立和威逼称臣。
- 议会政策也影响动机：领地制度为分封制时更倾向分封宗室，为中央直辖时更倾向收归直辖；附庸的臣属方针为争取自治时更倾向独立。
- 原版的「和平谈判」密谋由和谈取代。

各密谋的条件与结果见[附庸](vassals.md)、[王朝兴衰](cycle.md)、[战争与和谈](war.md)和[集团](blocs.md)。

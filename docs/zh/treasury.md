# 国库、军饷与营建

国库是国家的金币储备。原版中交给城主和国王的钱只进不出，建筑建成后也基本没有作用。模组为每个国家设置国库，让城市自行供养地方军，为建筑增加实际效果，并允许国家出资让城市增建建筑。

## 钱的流向

- **居民到城主**：照原版，居民将收入的一部分交给城主。
- **城主到国家**：城主按议会的[税收体制](parliament.md#内政)上缴，包税制 25%，分成制 50%，统收制 75%。上缴的钱 20% 归国王个人，其余进入国库。城主留下的部分，一半进入城市仓库。各城城主每年在国家的结算月、发饷之前，集中上缴这一年攒下的税。
- **附庸到宗主**：附庸国库的收入按宗主的[附庸贡赋](parliament.md#外交)比例交给宗主。

国库只存放金币，木材、石料和粮食存于城市仓库。选中王国时，底部信息栏的金币格显示国库余额。王国窗口和悬停提示中，「领袖财富」下方一行也显示国库余额。

## 养兵

地方兵由所在城市从仓库发饷，[禁军](armies.md)由国库发饷，每名士兵每年 0.5 金币。

- **征兵**：城市仓库够全体地方兵一年的军饷时才征召地方兵；国库够全体禁军一年的军饷时才补充禁军。军队规模因此随收入变化。统收制下城市留存的钱少，地方兵规模受限，兵力与金币向中央集中。
- **欠饷**：每年发饷时发不出的部分记为欠饷。欠饷期间不征召新兵，每年有四分之一的欠饷士兵退伍，其余士兵的伤害逐年下降，最多下降四分之一。
- **补发**：付清军饷后，伤害逐年恢复。

地方兵的欠饷显示在城市窗口和城市提示中，禁军的欠饷显示在王国窗口和王国提示中。

## 钱花在哪

| 来源 | 用途 |
|---|---|
| 城市仓库 | 建房、升级建筑（原版），地方兵的军饷和[军械](armies.md#军械) |
| 国库 | 禁军的军饷和军械，营建，国王发起的密谋，战败赔款 |
| 国王个人 | 自己的装备（原版） |

- **储备**：国库保留一笔储备，平时为两年的禁军军饷，战时翻倍；不在战时而接壤的最强异阵营邻国实力超过本国 1.5 倍时，增加一半，两者不叠加。军械和营建只使用储备以外的金币，各自的上限由议会的[财政重心](parliament.md#内政)决定，用不完的留在国库。
- **密谋**：国王发起密谋的花费从国库支出。
- **赔款**：战败方的国库和各城仓库按同一比例交出金币，进入胜方国库，见[战争与和谈](war.md#和约)。

## 建筑

设置中的「建筑增幅」开启时，几类原版建筑具有实际作用。同类建筑多建几座时效果叠加，但每增加一座，增幅减半。

| 建筑 | 作用 |
|---|---|
| 市场 | 居民赚取的钱增加，上缴的税随之增加 |
| 神庙 | 城市忠诚度上升；推行同文同教时，本城居民同化得更快 |
| 兵营 | 城市可供养的兵额增加 |
| 箭塔 | 国家的军械档次越高，每轮射出的箭越多 |
| 雕像 | 首都有雕像时，国王的声望逐年上升 |
| 风车 | 每座风车附近都可开辟农田（原版只认第一座） |

关闭「建筑增幅」后，这些建筑照原版，也不进行营建。

## 营建

营建是国家出资让某座城市增建一类建筑：国库出钱，该城市可多建一座，并立即选址开工。城里找不到空地时，不营建，也不花钱。每座城市每类建筑最多增建两座，城市越大，可营建的总数越多。

国家优先营建最需要的项目：税收多的城市建市场，忠诚度低的城市建神庙，前线和强邻边境建箭塔，战时或受威胁时建兵营，缺粮的城市建风车，资金充裕时给首都建雕像。项目确定后，资金不足时先积蓄，足够后开工。

营建建在哪个家族占有的城市（首都除外），该家族就对掌权家族获得 10 点恩情，议会关闭时不记。城市窗口中的「国家营建」一行列出国家在该城市营建过的建筑。

## 国库页

王国窗口左边的页签栏中，名人页签前面是国库页。

- **存金**：国库当前的金币，以及去年国库的结余。
- **流向图**：显示去年金币的来源与去向。来源包括上缴最多的几座城市、其余城市、附庸贡赋和赔款；去向包括国王（共和国为执政）所得、禁军军饷、军械、营建、密谋、交给宗主的贡赋和战败赔款。带子越宽，金额越大。
- **账簿**：记录国库的重大事项，如赔款、密谋、禁军欠饷与付清、税收体制变更、附庸称臣或离去、营建。

账目每年结算一次，新开的世界或刚装上模组时，需要到年底才有去年的流向。

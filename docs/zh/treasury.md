# 国库、军饷与营建

原版的钱交到城主和国王手里以后就只进不出，建筑盖好了也没什么用。现在每个国家有一个国库，城市要用自己的钱养兵，市场、神庙这些建筑有了实际作用，国家还能出钱给城市多盖建筑。钱在城市和中央两头都有地方花。

## 钱怎么流

- **居民 → 城主**：照原版，居民的收入交一部分给城主。
- **城主 → 国家**：城主按议会的[税收体制](parliament.md#内政)上缴：包税制 25%、分成制 50%、统收制 75%。上缴的钱一小部分归国王个人，其余进国库。城主留下的钱一半进城市仓库。每年年底各城城主把这一年攒下的税交上来。
- **附庸 → 宗主**：附庸国库的收入按宗主的[附庸贡赋](parliament.md#外交)交一份给宗主。

国库只存金子，木头、石头、粮食都留在城市仓库里。

选中王国时，底部信息栏的金币格显示国库。王国窗口和悬停提示里，「领袖财富」下面一行也是国库。

## 养兵

地方兵由所在的城从仓库发饷，[禁军](armies.md)由国库发饷，每人每年 0.5 金子。

- **征兵先看钱**：城市仓库够全体地方兵吃一年才征地方兵，国库够全体禁军吃一年才补禁军。所以军队规模跟着收入走：统收制下城市留的钱少，地方兵养不满，兵和钱都集中到中央。
- **欠饷**：每年发饷时发不出的部分算欠饷。欠饷期间不征新兵，每年有四分之一的欠饷士兵解甲归田，留下的士兵军心涣散，伤害逐年下降，最多降四分之一。
- **补发**：付清军饷后，伤害逐年恢复。

地方兵的欠饷显示在城市窗口和城市提示里，禁军的欠饷显示在王国窗口和王国提示里。

## 钱花在哪

| 谁的钱 | 花在哪 |
|---|---|
| 城市仓库 | 盖房、升级建筑（原版），地方兵的军饷和[军械](armies.md#军械) |
| 国库 | 禁军的军饷和军械，营建，国王发起的密谋，战败的赔款 |
| 国王个人 | 自己的装备（原版） |

- **储备**：国库先留出一笔储备，平时是两年禁军军饷，打仗时翻倍，挨着比自己强得多的邻国时多留一半。军械和营建只花储备以外的钱，各自最多花多少由议会的[财政重心](parliament.md#内政)决定，没花完的钱留在国库里存着。
- **密谋**：国王发起密谋时花国库的钱，够不够也看国库。
- **赔款**：战败时，国库和各城仓库都按同一比例交出金子，进胜方国库，见[战争与和谈](war.md#和约)。

## 建筑

几类原版建筑有了实际作用。同一类建筑多盖几座效果会叠加，但一座比一座少。

| 建筑 | 作用 |
|---|---|
| 市场 | 居民赚的钱变多，交上来的税也跟着变多 |
| 神庙 | 城市更忠诚；推行同文同教时，城里的人同化得更快 |
| 兵营 | 城市能养的兵变多 |
| 箭塔 | 国家的军械档次越高，一轮射出的箭越多 |
| 雕像 | 首都有雕像时，国王的声望逐年上涨 |
| 风车 | 每座风车附近都能开农田（原版只认第一座） |

设置里关掉「建筑增幅」时，这些建筑照原版，也不营建。

## 营建

国家出钱让某座城多盖一座建筑：这座城这一类建筑能多盖一座，国库出钱，当场照原版选址开工。城里找不到地方就不营建，也不花钱。长成的大城往往房子挨着房子，营建多落在还在长大的城市。每座城每类最多多盖两座，城越大能营建的越多。

国家会挑最需要的地方营建：税收多的城修市场，忠诚低的城修神庙，前线和强邻边境修箭塔，打仗或受威胁时修兵营，缺粮的城修风车，有钱时给首都修雕像。项目定下来以后，钱不够就先攒着，攒够了再开工。

营建修在哪个家族的城里，那个家族就欠王室一份人情。城市窗口里有一行「国家营建」，列出国家给这座城营建过的建筑。

## 国库页

王国窗口左侧页签栏里，名人页签上面是国库页：

- **存金**：国库现在有多少金子，和去年国库的结余。
- **流向图**：去年的钱从哪来、花到哪去。左边是来源（上缴最多的几座城、其余各城、附庸贡赋、赔款），汇进中间的竖条；竖条上段是国王（共和国是执政）分走的那份，下段是国库，从这里流向右边的禁军军饷、军械、营建、密谋、交给宗主的贡赋和战败赔款。收大于支时右边多一股「存入国库」，支大于收时左边多一股「动用存金」。带子越宽，钱越多。
- **账簿**：国库的大事：赔款、密谋、禁军欠饷和付清、改税收体制、附庸称臣或离去、营建。

账一年一结，新开的世界或刚装上模组时要等到年底才有去年的流向。

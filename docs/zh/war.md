# 战争与和谈

原版的战争要么无条件停战，要么一方灭国。现在交战双方打到差不多时会坐下来谈判，按战果签和约：白和平、赔款、交出附庸，或者称臣。

## 国家什么时候开战

国家打完一仗要隔一段时间才会再开战，挑对手时也会掂量兵力。这两样都看政体和议会的外交路线，见[政体](government.md#政体的脾气)和[议会与政策](parliament.md#外交)。挑对手时双方兵力按整个阵营算：宗主、附庸、盟友都算进去。

附庸不会自己开战，跟着宗主打，见[附庸](vassals.md#战争同进同退)。

## 战果

每场战争有一个战果，显示在战争窗口和悬停提示里，比如「攻方占优 35」，差距很小时显示「相持」。战果只看双方的主国：

- 丢的城占开战时的比例，丢得多的一方吃亏。
- 开战时的首都落到对方手里，大亏一笔。
- 兵力多的一方占一点优势。

## 什么时候谈

开战满 3 年后（设置里可调），双方国王都可以发起「和谈」：

- **领先方**：战果达到自己的期望时就想谈。好战的国王期望高，非要打到对方称臣；打得越久、自己死的人越多，期望就越低。
- **落后方**：落后得越多、打得越久，越想谈。

和谈做完时按当时的战果定结局。差距没到领先方的期望，算领先方拒绝，什么也不发生，之后还可以再谈。打成平手的战争，双方期望慢慢降下来，最后以白和平收场。

原版的「和平谈判」密谋不再出现。设置里关掉和谈就恢复原版。总体战不和谈。

## 和约

| 战果差距 | 和约 |
|---|---|
| 小于 20 | 白和平 |
| 20 到 50 | 赔款 |
| 50 到 80 | 多赔一些，交出附庸 |
| 80 以上 | 多赔一些，称臣，交出附庸 |

- **赔款**：败方国库和每座城仓库里的金子交出一部分（默认 20%，设置里可调），全部进胜方国库。
- **交出附庸**：败方的附庸挨个判定，和胜方接壤的有机会改投胜方，胜方的国王越擅长外交、越有野心，越容易接手。胜方正在衰落时接不了。
- **称臣**：败方成为胜方的附庸，带着积怨。没被胜方接手的附庸就此独立。

胜方本身是附庸时，交出的附庸和称臣的败方都归胜方的宗主。

## 战后

- **天命**：赔款档胜方 +2、败方 −4；交出附庸和称臣档胜方 +5、败方 −10。白和平不变。
- **战败之耻**：只赔了款或交了附庸的败方，对胜方的好感下降，十年内慢慢消失。
- 和约记进世界日志，战争窗口里显示和约内容和赔款明细。

## 独立战争

附庸发动的独立战争也走和谈。宗主谈到称臣档，附庸重新成为附庸；其他结局附庸都独立，照表赔款。

## 攻城

对所有军队都生效。原版攻城时，城里只要还有一个守方单位，进度就卡在 5%，攻方的队长进城后只会乱转，大城可能永远打不下来。现在：

- 攻方队长进城后直奔最近的守方战士、城主或国王，城里没人了就去城中心。
- 攻方在城里的人数达到守方的 5 倍时，守方挡不住，进度照常上涨，涨满就破城。

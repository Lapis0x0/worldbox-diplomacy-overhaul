# 王朝兴衰

大国会经历一个王朝周期：**新生 → 鼎盛 → 衰落 → 崩溃**。鼎盛时附庸归心、城市安稳、军队善战；衰落时人心浮动、各地叛乱；最后爆发大叛乱，国家四分五裂。撑过大叛乱的王朝能苟延残喘，也可能被将领推翻，换一个新王朝从头开始。

## 谁有周期

自己有 6 座城及以上、或者带着附庸的国家，附庸本身没有周期。当前阶段显示为一个王国特质，也写在王国窗口的副标题上，比如「帝国 · 鼎盛」。

设置里可以关掉王朝周期。

## 天命

推动周期的是**天命**，一个 0 到 100 的数。鼠标悬停在周期特质上，能看到天命和它的各项组成。

天命每年慢慢向「应得的天命」靠拢。应得的天命由两部分决定：

**治理**，平常在零上下浮动：

| 项 | 什么让它变好 |
|---|---|
| 城市归心 | 忠诚不为负的城市多 |
| 君主 | 君主的管理和智力高；王位空着时很差 |
| 附庸 | 附庸的整合度高 |
| 民生 | 无家可归的人少 |
| 尾大不掉 | 宗主自己只剩几座城、却带着一堆附庸时扣分 |

**老化**：每个王朝都会积累**积弊**，治理好的积累得慢。积弊早年几乎没有影响，到晚年越扣越多，所以再好的王朝也会走下坡路，只是活得更久。王朝每撑过一次大叛乱，还会留下**沉疴**，下一轮衰落来得更快。

战争和城市得失直接加减天命：

| 事件 | 天命 |
|---|---|
| 打赢一场战争 | +5（只谈到赔款时 +2） |
| 打输一场战争 | −10（只谈到赔款时 −4） |
| 得到一座城 | +1 |
| 失去一座城 | −2 |
| 首都被攻占 | 再 −15 |
| 中兴失败 | −10 |

白和平不加不减。

## 四个阶段

```
新生 ──天命 ≥ 70──▶ 鼎盛 ──天命 < 50──▶ 衰落 ──天命 < 20──▶ 大叛乱 ──▶ 崩溃
  ▲                    ▲                    │  ▲                             │
  │                    └──天命 ≥ 70（中兴）─┘  └──── 叛乱平息（平叛）───────┤
  └──────────────────────────── 将领夺权（改朝换代）──────────────────────────┘
```

- **新生**：国家刚长到 6 座城或刚有附庸时开始，天命 60。涨到 70 进入鼎盛，跌破 40 直接衰落。
- **鼎盛**：天命跌破 50 进入衰落。
- **衰落**：天命回到 70 就中兴，回到鼎盛；跌破 20，或者丢了首都，爆发大叛乱。
- **崩溃**：大叛乱以后。叛乱战争和独立战争打完，国家还够大的话就算**平叛**，回到衰落，天命 45；国家已经变小了，周期就没了。崩溃期间将领可能夺权，**改朝换代**后回到新生，积弊和沉疴一笔勾销，见[政体](government.md#乱世夺权)。

读档后第一次判定时，已经够大的国家直接算作鼎盛，各国的积弊随机，免得同一时间一起衰落。

## 各阶段的影响

| | 新生 | 鼎盛 | 衰落 | 崩溃 |
|---|---|---|---|---|
| 附庸对宗主的好感 | 加一些 | 加得多 | 扣，天命越低扣得越多 | 同衰落 |
| 城市忠诚 | — | 加 | 扣，天命越低扣得越多 | 同衰落 |
| 附庸的整合度 | 慢慢上升 | 慢慢上升 | 下降，天命越低降得越快 | 降得更快 |
| 附庸密谋独立 | 照常 | 照常 | 不再顾忌实力差距 | 同衰落 |
| 叛乱的城改分封为附庸 | 一半 | 大多数 | 少数 | 不会 |
| 威逼邻国称臣 | 可以 | 可以 | 不能 | 不能 |
| 政体事件 | — | 共和国可能称帝 | — | 将领可能夺权 |

衰落刚开始时几乎感觉不到，天命跌到 30 上下，忠诚最低的城就开始自己造反，大叛乱之前各地已经零星起事。这些修正在原版的明细里叫「太平盛世」「国运衰微」「宗主国运」。

**军队伤害**也跟着天命走：天命 100 时全国单位伤害 +10%，50 时照常，跌到 0 时 −25%。衰落末期的军队明显打不动。

原版攻下一座城后全国十年加忠诚的「新征服」去掉了，打胜仗的好处改由天命体现。

## 中兴

衰落中的天命回到 70 就会中兴。国王（共和国是执政）也可以主动发起「中兴」密谋，需要 5 级、50 金币，一般一两年做完。天命越低，治国型的君主越想试试。

做完时掷一次成败，默认三成成功，君主的管理和智力越高越容易：

- 成功：积弊大减，天命至少回到 70，回到鼎盛。
- 失败：天命 −10，相当于打输一场仗，之后还可以再试。

5 级的君主不多，一个衰落的王朝能不能中兴，主要看它能不能出一位雄主。

## 大叛乱

天命跌破 20、衰落期丢了首都，或者用神力**大叛乱**，都会引发大叛乱：

1. 国内几座忠诚最低、彼此不相邻的城同时起事，国家越大起事的地方越多，最多 6 处。国家至少要有 3 座城。
2. 叛军从各处向外扩张，吞掉原国家首都以外六成的城。
3. 每个附庸按整合度掷一次，决定反不反：刚投降的附庸几乎都会反，行省很少反。

国家随即进入崩溃期，屏幕上方会提示。

## 小宗主

大叛乱以后，宗主常常只剩几座城，附庸却还在。自己不到 6 座城的宗主压不住附庸：天命扣分（「尾大不掉」），附庸好感下降（「宗主势微」），整合度逐年下滑。只剩三四座城的宗主，几十年内附庸会陆续走光。宗主重新长到 6 座城，这些压力就没了。

## 手动推动

- 神力**天命**把国家推进一个阶段：没有周期 → 新生 → 鼎盛 → 衰落 → 大叛乱。
- 在特质编辑器里换成另一个阶段的特质，国家从这一年起进入那个阶段。

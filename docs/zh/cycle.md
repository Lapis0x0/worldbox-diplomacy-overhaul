# 王朝兴衰

王朝周期是大国经历的四个阶段：**新生、鼎盛、衰落、崩溃**。鼎盛时附庸归附、城市安定、军队战力提升；衰落时人心浮动、各地叛乱；最终爆发大叛乱，国家分裂。度过大叛乱的王朝回到衰落，也可能被将领推翻，由新王朝重新开始。

## 适用范围

周期适用于自己拥有 6 座城及以上，或带有附庸的国家，附庸本身没有周期。当前阶段显示为王国特质，也写在王国窗口的副标题上，例如「帝国 · 鼎盛」。设置中可以关闭王朝周期。

## 天命

天命是推动周期的数值，范围为 0 到 100。鼠标悬停在周期特质上，可以查看天命及其各项构成。

天命每年向「应得天命」靠拢。应得天命由两部分决定。

**治理**通常在零附近浮动。

| 项目 | 使其上升的情况 |
|---|---|
| 城市归心 | 忠诚度不为负的城市多 |
| 君主 | 君主的管理和智力高；王位空缺时很低 |
| 附庸 | 附庸的整合度高 |
| 民生 | 无家可归的人少 |
| 尾大不掉 | 宗主自己城市很少却带着众多附庸时扣减 |

**老化**：每个王朝都会积累**积弊**，治理越好积累越慢。积弊在早期几乎没有影响，晚期扣减迅速增加，因此再好的王朝也会走向衰落，只是持续更久。王朝每度过一次大叛乱，会留下**沉疴**，使下一轮衰落来得更早。

战争和城市得失直接增减天命。

| 事件 | 天命 |
|---|---|
| 战争获胜 | +5（和谈只到赔款档时 +2） |
| 战争战败 | -10（和谈只到赔款档时 -4） |
| 得到一座城市 | +1 |
| 失去一座城市 | -2 |
| 首都被攻占 | 额外 -15 |
| 中兴失败 | -10 |

白和平不改变天命。

## 四个阶段

```
新生 ──天命 ≥ 70──▶ 鼎盛 ──天命 < 50──▶ 衰落 ──天命 < 20──▶ 大叛乱 ──▶ 崩溃
  ▲                    ▲                    │  ▲                             │
  │                    └──天命 ≥ 70（中兴）─┘  └──── 叛乱平息（平叛）───────┤
  └──────────────────────────── 将领夺权（改朝换代）──────────────────────────┘
```

- **新生**：国家达到 6 座城或有了附庸时开始，天命为 60。天命达到 70 进入鼎盛，低于 40 直接进入衰落。
- **鼎盛**：天命低于 50 进入衰落。
- **衰落**：天命回升到 70 时中兴，回到鼎盛；天命低于 20，或首都丢失，爆发大叛乱。
- **崩溃**：大叛乱之后的阶段。叛乱战争和独立战争结束后，国家仍然够大时称为**平叛**，回到衰落，天命为 45；国家已经缩小时，周期消失。崩溃期间，将领可能夺权，**改朝换代**后回到新生，积弊和沉疴清零，见[政体](government.md#乱世夺权)。

## 各阶段的影响

| | 新生 | 鼎盛 | 衰落 | 崩溃 |
|---|---|---|---|---|
| 附庸对宗主的好感 | 小幅上升 | 大幅上升 | 下降，天命越低降得越多 | 同衰落 |
| 城市忠诚度 | — | 上升 | 下降，天命越低降得越多 | 同衰落 |
| 附庸整合度 | 缓慢上升 | 缓慢上升 | 下降，天命越低降得越快 | 下降更快 |
| 附庸密谋独立 | 照常 | 照常 | 不再受实力对比限制 | 同衰落 |
| 叛乱的城市改为分封 | 一半 | 多数 | 少数 | 不会 |
| 威逼邻国称臣 | 可以 | 可以 | 不能 | 不能 |
| 政体事件 | — | 共和国可能称帝 | — | 将领可能夺权 |

这些修正在原版的明细中显示为「太平盛世」「国运衰微」「宗主国运」。衰落初期影响很小，天命降到 30 左右时，忠诚度最低的城市开始自行叛乱，大叛乱之前各地已有零星起事。

**军队伤害**也随天命变化：天命 100 时全国单位伤害 +10%，50 时照常，降到 0 时 -25%。

原版攻下城市后全国十年的「新征服」忠诚加成已经去除，战胜的收益改由天命体现。

## 中兴

衰落中的天命回升到 70 时，王朝中兴。国王（共和国为执政）也可以主动发起「中兴」密谋，需要 5 级和 50 金币，通常一两年完成。天命越低，擅长治国的君主越倾向发起。

密谋完成时判定成败，默认成功率为三成，君主的管理和智力越高越容易成功。

- 成功：积弊大幅减少，天命至少回到 70，回到鼎盛。
- 失败：天命 -10，之后可以再次尝试。

## 大叛乱

天命低于 20、衰落期丢失首都，或使用神力**大叛乱**时，爆发大叛乱。

1. 国内忠诚度最低且互不相邻的几座城市同时起事，国家越大起事的城市越多，最多 6 座。国家至少要有 3 座城。
2. 叛军向外扩张，占领原国家首都以外约六成的城市。
3. 每个附庸按整合度判定是否起兵，刚投降的附庸几乎都会起兵，行省很少起兵。

国家随即进入崩溃期，屏幕上方显示提示。关闭世界法则「叛乱」后，王朝不会自行爆发大叛乱，天命降到底也停留在衰落期，神力**大叛乱**仍可使用。

## 小宗主

大叛乱后，宗主常常只剩几座城市，却仍有附庸。自己不足 6 座城的宗主难以约束附庸：天命下降（「尾大不掉」），附庸好感下降（「宗主势微」），整合度逐年下降。只有三四座城的宗主，其附庸会在几十年内陆续离去。宗主重新达到 6 座城后，这些影响消失。

## 手动推动

- 神力**天命**使国家进入下一阶段：无周期、新生、鼎盛、衰落、大叛乱。
- 在特质编辑器中换成另一阶段的特质，国家从当年起进入该阶段。

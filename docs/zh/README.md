# 外交大修玩家指南

外交大修让 WorldBox 里的国家有了内政和外交：大国会分封附庸、威逼邻国称臣，附庸会归心也会造反；国家有政体和议会，各家族为政策争吵；王朝会兴盛、衰落，最后在大叛乱里分崩离析；战争打到一定程度会坐下来谈判；钱进国库，国库养着中央禁军。你可以只当旁观者，也可以用神力插手，或者直接指挥军队。

## 装上以后你会看到

- **国名带上政体**：比如「科英布拉公国」「卡斯蒂利亚帝国」。王国窗口的副标题写着政体，附庸接上宗主名，大国接上王朝的阶段，比如「帝国 · 鼎盛」。
- **王国特质里多了几组**：政体、王朝周期（新生、鼎盛、衰落、崩溃）、附庸的整合度（积怨、离心、归附、一体）。鼠标悬停在特质上能看到具体数值。
- **王国窗口左边多了两个页签**：议会，以及选举与任命。
- **王国窗口里多了国库**：在「领袖财富」下面。
- **好感和忠诚明细里多了几项**：「效忠宗主」「宗主国运」「政见不合」「削藩」等，都能在原版的明细里看到。
- **世界日志多了很多事件**：称臣、分封、中兴、大叛乱、改制、称帝、和约。
- **底部多了一个「外交大修」Tab**：神力和设置都在这里。

装模组之前的存档可以直接用，缺少的数据在游戏里自动补上。

## 几个系统怎么连在一起

- **王朝周期是中心。** 鼎盛的大国附庸归心、城市安稳；衰落的大国附庸离心、各地叛乱，最后爆发大叛乱。共和国在鼎盛时可能称帝，崩溃时将领可能夺权。
- **附庸是外交的基本单位。** 投降、分封、称臣都会产生附庸。宗主和附庸战争同进同退；王朝衰落时附庸离心，大叛乱时纷纷独立。
- **战争靠谈判结束。** 打到差不多时双方和谈，按战果赔款、交出附庸或称臣。
- **国策由家族决定。** 家族按占的城分议席，投票决定税收、兵制、分封、外交路线。国家扩张以后，地方家族会壮大到能和王室分庭抗礼。
- **钱有去处。** 城主上缴的钱进国库，国库养禁军、发起密谋、支付赔款。

想看每条规则的精确数值和公式，见[开发文档](../dev/README.md)。

# 外交大修玩家指南

外交大修为 WorldBox 的国家加入内政与外交：大国分封附庸、威逼邻国称臣；国家有政体和议会，各家族为政策表决；王朝经历兴衰，最终在大叛乱中分裂；战争打到一定程度后双方谈判；国库供养禁军。你可以旁观，可以用神力干预，也可以直接指挥军队。

## 安装后的变化

- **国名带有政体**：例如「科英布拉公国」「卡斯蒂利亚帝国」。王国窗口的副标题写有政体，附庸接宗主名，大国接王朝阶段，例如「帝国 · 鼎盛」。
- **王国特质新增几组**：政体、王朝周期（新生、鼎盛、衰落、崩溃）、附庸的整合度（积怨、离心、归附、一体）。悬停可以查看具体数值。
- **王国窗口左边新增页签**：议会，以及选举与任命，国库页位于名人页签之前。
- **好感和忠诚明细新增项目**：「效忠宗主」「宗主国运」「政见不合」「削藩」等。
- **世界日志新增事件**：称臣、分封、中兴、大叛乱、改制、称帝、和约。
- **底部新增「外交大修」Tab**：神力和设置都在这里。

装载模组之前的存档可以直接使用，缺少的数据会自动补齐。

## 系统之间的联系

- **王朝周期**影响附庸的整合度、城市的忠诚度和叛乱的概率。共和国在鼎盛期可能称帝，崩溃期可能被将领夺权。
- **附庸**由投降、分封和称臣产生。宗主与附庸同进同退，王朝衰落时附庸离心，大叛乱时纷纷独立。
- **战争**以和谈结束，按战果赔款、让出附庸或称臣。
- **议会**决定税收、兵制、分封和外交路线。家族可以结成集团一同投票。
- **国库**接收城主上缴的钱，用于供养禁军、发起密谋和支付赔款。

各项规则的精确数值见[开发文档](../dev/README.md)。

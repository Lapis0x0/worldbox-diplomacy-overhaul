# 神力与设置

所有神力位于底部的「外交大修」Tab，从左到右分为四组：设置、附庸、战争、城镇管理。需要点击两次的神力，点击第一个目标后地图上会画出箭头；再次点击第一个目标即取消。

## 附庸

| 神力 | 用法 | 效果 |
|---|---|---|
| 册封附庸 | 先点宗主，再点附庸 | 后者成为前者的附庸 |
| 煽动独立 | 点一个附庸 | 它立即向宗主发动独立战争 |
| 大叛乱 | 点一个国家 | 立即爆发大叛乱 |
| 天命 | 点一个大国 | 王朝周期推进一个阶段，衰落期再推进则爆发大叛乱 |
| 分封附庸 | 点一座非首都城市 | 它自立为国，成为原国家的附庸 |

规则见[附庸](vassals.md)和[王朝兴衰](cycle.md)。

## 战争

| 神力 | 用法 | 效果 |
|---|---|---|
| 指挥军队 | 先点一支军队，再点目标 | 别国城市为进攻，友方城市为驻扎，空地为扎营，点击驻地为解除 |
| 举国进攻 | 先点出兵的国家，再点目标城市 | 所有军队进攻别国城市，或全军前往友方城市驻扎 |
| 交还指挥 | 点一个国家 | 它所有听从玩家命令的军队交还 AI |

不使用神力时，也可以框选军队并右键下令，见[指挥军队](commands.md)。

## 城镇管理

| 神力 | 用法 | 效果 |
|---|---|---|
| 移交城市 | 先点一座城市，再点接收的国家 | 城市归接收方，首都不能移交 |
| 吞并王国 | 先点吞并方，再点被吞并方 | 被吞并方的城市和附庸全部归吞并方；吞并方本身是附庸时，这些附庸获得自由 |

## 设置

点击 Tab 最左边的设置按钮打开。每个系统一个开关，点击后立即生效。

| 分块 | 开关 | 作用 |
|---|---|---|
| 外交 | 分封与称臣 | 大国分封城市，弱小的邻国称臣 |
| | 和谈 | 战争拖久后双方谈判，按战果签订和约；关闭后恢复原版的和平谈判 |
| 内政 | 议会与政策 | 家族按议席表决国家的各项政策；关闭后政策不再生效，税收按原版的贡赋特质 |
| | 王朝周期 | 大国经历新生、鼎盛、衰落、崩溃 |
| | 政体随国力变化 | 政体随国力和附庸状态更新，手动选择的政体保留 |
| | 历史事件改制 | 王室绝嗣、共和国称帝、乱世夺权 |
| 军事 | 军队大修 | 禁军、国家指挥、命令与框选、攻城、军械与军饷；关闭后军队照原版，指挥军队的神力一并移除 |
| 显示 | 国名显示政体 | 例如「科英布拉公国」 |
| | 推行政策提示 | 国家推行政策时在左上角提示；关闭后只记入世界历史 |
| 性能 | 优化原版计算 | 不改变游戏结果，大地图上帧率提高约 20%，遇到异常时可以关闭 |

所有开关默认开启，「恢复默认」将它们全部开启。

# 附庸

附庸是臣属于另一个国家（宗主）的国家。附庸保留自己的国王、城市和军队，但随宗主作战，不能自行宣战或结盟。附庸的整合度逐渐上升，最终成为宗主的行省；宗主衰落时，附庸可能起兵独立。

## 宗主和附庸

- 附庸的王国窗口中有「宗主」一栏，副标题写作「公国 · 宗主名」。宗主的王国窗口在「外交」下方增加「附庸」一行，按整合度从高到低排列，悬停旗帜可查看整合度、对宗主的好感和去年上缴的贡赋。
- 地图上附庸的边界线使用宗主的颜色，行省的填充色也使用宗主的颜色。
- 宗主不能同时是他国的附庸，有附庸的国家也不能成为他国的附庸。
- 宗主灭亡时，它的所有附庸获得自由。

**阵营**：宗主、它的附庸以及宗主的盟友组成一个阵营。同一阵营的国家不会互相开战；AI 选择对手时按整个阵营的兵力计算，进攻附庸需要面对宗主及其盟友。联盟地图也按阵营显示。

### 战争同进同退

- 宗主遭到进攻时，所有附庸参战防守。
- 宗主主动进攻时，附庸按整合度决定是否参战（最低 30%），行省一定参战。
- 附庸遭到进攻时，宗主出兵救援。
- 附庸境内有城市叛乱时，附庸自行平叛；宗主按整合度决定是否出兵，行省的宗主一定出兵。
- 宗主退出战争时，附庸一同退出。除平叛外，附庸不会卷入宗主未参与的战争。

宗主与附庸出现在同一场战争的对立两方时（例如玩家用神力让宗主攻打自己的附庸），附庸关系立即解除。

## 附庸从哪来

| 途径 | 过程 | 初始整合度档次 |
|---|---|---|
| 投降 | 战争中败方称臣，见[战争与和谈](war.md) | 积怨 |
| 和谈中让出 | 败方把自己的附庸让给胜方 | 离心 |
| 威逼称臣 | 强国遣使威逼弱小的邻国 | 离心 |
| 神力册封 | 玩家用神力指定宗主和附庸 | 离心 |
| 独立战争失败 | 附庸发动独立战争，宗主获胜后重新成为附庸 | 积怨 |
| 叛乱改分封 | 城主叛乱成功，宗主将该城分封给他 | 归附 |
| 攻城改分封 | 国家攻下超出治理上限的城市，分封给当地居民 | 一体（行省） |
| 分封宗室 | 国王将边远城市分封给王室成员 | 一体（世袭行省） |
| 神力分封 | 玩家用神力让一座城市自立为附庸 | 一体（行省） |

- **叛乱改分封**：原版中城主叛乱成功后会自立并开战。现在宗主可能将该城分封出去，得到附庸而不是敌人。王朝鼎盛时多数会分封，衰落时很少，崩溃时不会。首都和相邻的城市不会被分封。
- **攻城改分封**：国家达到原版的治理城市上限后，再攻下的城市多数不并入本国，而是并给相邻的小附庸，或分封给城中居民成立新附庸。军事共和国从不分封。
- **附庸攻下的城市**：附庸随宗主出征，靠战争最多扩张到 3 座城。再攻下的城市归宗主或其他附庸，该附庸整合度略有下降。
- **威逼称臣**：强国的国王可以威逼接壤的弱国。对方必须没有处于战争中，自己不是附庸也没有附庸，对强国的好感不为负，并且强国连同附庸的实力至少是对方整个阵营的 3 倍（帝国为 2 倍）。有盟友的国家因此不容易被威逼。衰落中的国家不会发起。
- **分封宗室**：城市超过治理上限的君主国，国王将离首都最远的几座城市（最多 3 座）分封给王室成员，优先分封给自己的子女。

领地制度会改变分封的频率，见[议会与政策](parliament.md#内政)。分封和威逼称臣可以在设置中关闭。

## 整合度

整合度表示附庸离完全归化的程度，显示为王国特质，悬停可查看具体数值。

| 特质 | 状态 |
|---|---|
| 积怨 | 对宗主旧怨未消 |
| 离心 | 与宗主关系疏远 |
| 归附 | 逐渐归附宗主 |
| 一体 | 与宗主融为一体，成为行省 |

整合度每年变化，影响因素如下。

| 使整合度上升 | 使整合度下降 |
|---|---|
| 宗主处于新生或鼎盛 | 宗主处于衰落或崩溃，天命越低降得越快 |
| 与宗主领土接壤 | 与宗主不接壤 |
| 与宗主文化、宗教相同 | 与宗主不是同一物种 |
| 两国国王出自同一家族 | 附庸的城市数达到宗主的一半以上 |
| 附庸的臣属方针为忠诚臣属 | 宗主自己只有几座城 |
| 宗主赢得战争 | 宗主输掉战争 |
| | 宗主的附庸政策为自治特许，或附庸的臣属方针为争取自治 |

处于积怨档的附庸上升较慢。盛世中接壤且文化相同的附庸，叛乱改分封而来的约 7 年成为行省，威逼称臣而来的约 18 年，投降而来的约 40 年。宗主衰落后，行省约十年退回普通附庸。

## 行省

整合度达到「一体」后，附庸成为行省。

- **世袭行省**：附庸的国王与宗主出自同一家族，例如被分封出去的宗室。保留王室，照常世袭，领袖称亲王。
- **行省**：其他情况。改为共和制，由议会选出总督。

两种行省都一定随宗主参战，大叛乱时很少造反，地图上使用宗主的颜色。宗主更换王朝，或世袭行省自己绝嗣时，世袭行省变为普通行省。

### 收归直辖

不是附庸、不处于衰落或崩溃期，且城市数未达治理上限的宗主可以发起「收归直辖」密谋，逐座收回行省的城市，接壤且整合度高的行省优先。空位足够时，整个行省并入宗主。

分封宗室与收归直辖相互配合：城市过多时分封出去，有空位时从行省收回，宗主的直辖领土因此围绕治理上限调整。每年宗主与行省之间还会整理一次版图，被对方包围的飞地可能划归对方。

## 附庸的好感

附庸对宗主的好感明细中，包含以下几项。

- **效忠宗主**：固定的好感加成。
- **宗主国运**：宗主鼎盛时为加成，衰落时为减损，天命越低减损越多。
- **宗主势微**：宗主自己不足 6 座城时为减损。
- **共同敌人**（原版）：仅在附庸自己遭到攻击、宗主出兵救援的战争中计入。
- **自治特许**、**强制同化**、**附庸贡赋**：宗主的政策，见[议会与政策](parliament.md#外交)。

## 独立

附庸的国王可以发起「独立密谋」，成功后向宗主发动独立战争。

- **条件**：宗主处于衰落或崩溃期，或者宗主相对附庸足够弱。整合度越高，要求宗主越弱。
- **意愿**：附庸对宗主的好感越低、国王性格越好战，越倾向发起；宗主在别处进行大规模战争时，整合度低的附庸更倾向趁机起兵。

宗主赢得独立战争时，附庸重新成为附庸；其他结果下，附庸彻底独立。大叛乱期间，附庸也会按整合度起兵独立。

## 用神力操作

- **册封附庸**：先点击宗主，再点击附庸。
- **分封附庸**：点击一座非首都城市，它自立为国，成为原国家的附庸。
- **煽动独立**：点击一个附庸，它立即向宗主发动独立战争。

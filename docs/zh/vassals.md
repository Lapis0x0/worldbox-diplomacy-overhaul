# 附庸

附庸是臣属于另一个国家（宗主）的国家。附庸保留自己的国王、城市和军队，但跟着宗主打仗，不能自己宣战或结盟。附庸会慢慢归心，最后成为宗主的行省；也会积怨，等宗主衰落时起兵独立。

## 宗主和附庸

- 王国窗口里有「宗主」或「附庸」一栏，附庸的副标题写成「公国 · 宗主名」。
- 地图上附庸的边界线用宗主的颜色，行省连填充色也用宗主的。
- 宗主不能同时是别人的附庸，有附庸的国家也不能成为别人的附庸。
- 宗主灭亡时，它的附庸全部获得自由。

**集团和阵营**：宗主和它的附庸是一个集团，再加上宗主的盟友是一个阵营。同一阵营的国家不会互相开战；AI 挑对手时按整个阵营的兵力算，打附庸就要面对宗主和它的盟友。联盟地图也按阵营显示。

### 战争同进同退

- 宗主挨打，所有附庸都来防守。
- 宗主主动进攻，附庸按整合度决定参不参战，行省一定参战。
- 附庸挨打，宗主来救。
- 宗主退出战争时，附庸一起退出。附庸不会卷进宗主没参加的战争。

宗主和附庸出现在同一场战争的两边（比如玩家用神力让宗主打自己的附庸），附庸关系立即解除。

## 附庸从哪来

| 途径 | 怎么发生 | 刚成为附庸时 |
|---|---|---|
| 投降 | 战争打到败方称臣，见[战争与和谈](war.md) | 积怨 |
| 和谈中被让出 | 败方把自己的附庸交给胜方 | 离心 |
| 威逼称臣 | 强国遣使威逼弱小邻国 | 离心 |
| 叛乱改分封 | 城主密谋叛乱成功，宗主把这座城封给他 | 归附 |
| 攻城改分封 | 大国打下超出治理能力的城，封给当地人 | 一体（行省） |
| 分封宗室 | 国王把边远的城封给王室成员 | 一体（世袭行省） |

**叛乱改分封**：原版里城主叛乱成功会自立并开战。现在宗主可能把这座城封出去，得到一个附庸而不是一个敌人。王朝鼎盛时大多会分封，衰落时很少，崩溃时不会。首都和挨着首都的城不会分封。

**攻城改分封**：国家已经到了原版的治理城市上限，再打下的城多半不并入，而是并给旁边的小附庸，或者封给城里的居民建一个新附庸。军事共和国从不分封。

**附庸打下的城**：附庸跟着宗主出征，最多靠打仗长到 3 座城，再打下的城归宗主或分给别的附庸，附庸会因此有点不满。

**威逼称臣**：强国的国王可以遣使威逼一个接壤的弱小邻国。对方要满足：没在和强国打仗，自己不是附庸也没有附庸，对强国的好感不为负，而且强国连同附庸的实力至少是对方整个阵营的 3 倍（帝国 2 倍）。有盟友撑腰的国家不容易被吓住。衰落中的国家不会这么做。

**分封宗室**：城市超过治理上限的君主国，国王会把离首都最远的几座城封给一位王室成员，最多 3 座，优先封给自己的子女。

领地制度会改变分封的频率，见[议会与政策](parliament.md#内政)。设置里可以关掉分封和威逼称臣。

## 整合度

每个附庸有一个整合度，表示它离归化还有多远。整合度显示为一个王国特质，鼠标悬停能看到具体数字：

| 特质 | 状态 |
|---|---|
| 积怨 | 对宗主旧怨未消 |
| 离心 | 与宗主貌合神离 |
| 归附 | 渐渐归心于宗主 |
| 一体 | 与宗主融为一体，成为行省 |

整合度每年变动：

| 让它上升 | 让它下降 |
|---|---|
| 宗主处在新生或鼎盛 | 宗主处在衰落或崩溃，天命越低降得越快 |
| 和宗主的领土接壤 | 隔着别国或海洋 |
| 和宗主同文化、同宗教 | 不是同一个物种 |
| 两国国王出自同一家族 | 附庸的城市有宗主一半以上 |
| 附庸的臣属方针是忠诚臣属 | 宗主自己只剩几座城 |
| 宗主打赢战争 | 宗主打输战争 |
| | 宗主给了自治特许，或附庸在争取自治 |

处在积怨中的附庸归化得更慢。盛世里接壤、同文化的附庸，叛乱改分封来的大约 7 年成为行省，威逼称臣来的大约 18 年，投降来的要 40 年左右。宗主衰落以后，行省十年左右就会退回普通附庸。

## 行省

整合度涨到「一体」，附庸成为行省：

- **世袭行省**：附庸的国王和宗主出自同一家族，比如分封出去的宗室。保留王室，照常世袭，领袖称亲王。
- **行省**：其他情况。改成共和制，由议会选举总督。

两种行省都一定跟着宗主参战，大叛乱时很少造反，地图上用宗主的颜色。宗主换了王朝、或世袭行省自己绝嗣，世袭行省会变成普通行省。

### 收归直辖

城市还没到治理上限的宗主，可以发起「收归直辖」密谋，把行省的城一座座收回来，接壤的、整合度高的行省优先。空位够的话整个行省并入宗主。

分封宗室和收归直辖一来一回：城太多就分封出去，有空余就从行省收回来，宗主的直辖领土会围着治理上限调整。

另外，每年宗主和它的行省之间会整理一次版图：被对方包围的飞地有机会划给对方。

## 附庸的好感

附庸对宗主的好感里有这几项，在原版的好感明细里能看到：

- **效忠宗主**：固定加一笔。
- **宗主国运**：宗主鼎盛时加，衰落时扣，天命越低扣得越多。
- **宗主势微**：宗主自己不到 6 座城时扣。
- **共同敌人**（原版）：只有附庸自己挨打、宗主来救的那场战争才算。
- **自治特许**、**强制同化**、**附庸贡赋**：宗主的政策，见[议会与政策](parliament.md#外交)。

## 独立

附庸的国王可以发起「独立密谋」，成功后向宗主发动独立战争。能不能发起，看宗主压不压得住：

- 宗主正在衰落或崩溃，随时可以发起。
- 否则要宗主的实力相对附庸足够弱，整合度越高，要求宗主弱得越多。

想不想发起，看附庸对宗主的好感和国王的性格：好感越低越想反，积怨越深越记仇；宗主在别处打大仗时，离心的附庸更想趁机起兵。

独立战争宗主打赢，附庸重新成为附庸；其他结局，附庸彻底独立。大叛乱时，附庸也会按整合度纷纷起兵。

## 用神力操作

- **册封附庸**：先点宗主，再点附庸。
- **分封附庸**：点一座非首都城市，它自立为国，成为原国家的附庸。
- **煽动独立**：点一个附庸，它立即向宗主发动独立战争。

# 禁军与地方军

每个国家的兵分成两部分：**禁军**由国库供养、国家统一调度，负责出征和救援；**地方军**由各城自己养，以守卫边境为主。两者的比例由议会的[兵制](parliament.md#军事)决定。

## 禁军

- 都城的兵全部编入禁军，其他城按兵制抽一部分，其余是地方兵。
- 禁军的兵户籍还在本城，只是编进禁军服役。每月各城的禁军人数向名额调整，多了退回地方，少了从地方兵里调。
- 禁军每支最多 100 人，名字是「国名禁军 I」「国名禁军 II」这样。新兵就近编进没满的禁军编队。驻扎在同一座城的小编队会合并。
- 地图上禁军的军旗是金边深色布，中间一颗金星，地方军用原版的旗。
- 一座城被敌国攻占，它编入禁军的兵就地溃散。打下敌人的城，也就削弱了敌人的禁军。

### 国家怎么调度禁军

国家每月给闲着的禁军编队派任务，任务一直做到结束：

| 任务 | 什么时候 | 做到什么时候 |
|---|---|---|
| **救援** | 本国或附庸的城被敌军压着，敌军比守军多 | 敌军走后再守一个月。城丢了就转为出征夺回 |
| **出征** | 有仗打，没有城要救 | 城打下来、停战，或者打残了转去休整 |
| **休整** | 出征或救援打残了 | 在最近的本国城市补员，补到八成或者满半年 |
| **待命** | 有仗打但打不动，或者没仗打 | 随时接新任务。和平时一支守都城，其余守挨着最强邻国的边境 |

- 救援从离得最近的编队派起，直到兵力足够压过敌军。都城告急最优先，能把在外出征的编队拉回来。
- 出征优先挑人口多、守军少、离得近的城，敌国都城更有吸引力。国家会先集中兵力打一座城，兵力足够才分兵。
- 你亲自下过命令的编队，国家不插手，命令解除后再接管。

## 地方军

城主自己的兵。兵制是贵族私兵时，地方军照原版行事：兵凑够七成就去打最近的敌城。其他兵制下地方军以守为主：

- **本城被敌军压着**：回城驻守。
- **打仗时**：去最近的边境城市驻守。打下一座敌城后，那座城就是新的驻地。
- **出击**：同一座驻地里的地方军合起来，兵力不少于旁边某座敌城的守军，就一起去打。
- **和平时**：回到本城附近照原版活动。

## 军械

国家给禁军、每座城给自己的地方兵置办统一的制式装备：一件武器，加同一材质的头盔、胸甲、靴子。材质从铜开始，一档档往上升：铜、青铜、铁、钢、秘银、精金。

| | 禁军 | 地方兵 |
|---|---|---|
| 谁出钱 | 国库，按议会的[军械拨款](parliament.md#军事) | 本城仓库 |
| 先留出 | 两年的禁军军饷 | 两年的地方兵军饷和盖房的钱 |
| 词条 | 比民间打造的多 | 比民间打造的多，不如禁军 |
| 材料 | 向本国各城收购，买不到的向商队买 | 只用本城仓库里的 |

- **兵种**：大约四分之一是弓手，文化喜欢弓的国家一半是弓手。近战兵发文化偏好的武器，剑、斧、锤或矛。
- **换装**：每年发完军饷后，装备最差的兵先换。比制式好的装备留着不动。先从仓库里找能用的旧装备，没有才花钱买。
- **升档**：大部分兵装备齐了，第二年就升一档材质。秘银和精金商队不卖，要本国存货够全军换装才会升到这两档。
- **修理**：国家和城市给自己发的装备付钱修理，和平时期基本不花钱。
- **回收**：换下来的装备回炉退一部分钱，守城战死的兵留下的装备会被城里收回。

王国窗口里显示禁军的现行制式，城市窗口里显示地方兵的制式。选「自备军械」时禁军不发装备，照原版自己打造。

## 军饷

禁军和地方兵都要发饷，发不出来会裁员、战斗力下降，见[国库与军饷](treasury.md#养兵)。

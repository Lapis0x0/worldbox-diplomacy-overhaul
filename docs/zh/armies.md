# 禁军与地方军

每个国家的兵分为两部分。**禁军**由国库供养、国家统一调度，负责出征和救援；**地方军**由各城自己供养，以守卫边境为主。两者的比例由议会的[兵制](parliament.md#军事)决定。

在设置中关闭「军队大修」后，军队照原版运行：没有禁军和军饷，由城市自行出兵，指挥军队的神力也一并移除。

## 禁军

- 都城的兵全部编入禁军，其他城市按兵制抽取一部分，其余为地方兵。
- 编入禁军的兵户籍仍在本城，每月各城的禁军人数向名额调整：超出的退回地方，不足的从地方兵中调入。
- 每支禁军编队最多 100 人，命名为「国名禁军 I」「国名禁军 II」等。新兵编入就近未满员的编队，驻在同一城市的编队互相补员。
- 地图上禁军的军旗为金边深色旗面，中间有一颗金星；地方军使用原版军旗。
- 城市被敌国攻占时，它编入禁军的兵就地溃散。因此攻下敌国城市会削弱其禁军。

### 国家调度

国家每月给没有任务的禁军编队分配任务，任务执行到结束为止。

| 任务 | 条件 | 结束时间 |
|---|---|---|
| **救援** | 本国或附庸的城市被敌军围压，敌军多于守军 | 敌军撤离一个月后。城市丢失时转为出征夺回 |
| **出征** | 处于战争中，且没有需要救援的城市 | 城市攻下、停战，或兵力受损后转为休整 |
| **休整** | 出征或救援后兵力受损 | 在最近的本国城市补员，补到出发时的八成或满半年 |
| **待命** | 处于战争中但无法进攻；和平时人数不足一半 | 可随时接受新任务 |

- 救援从最近的编队派起，兵力足以压过敌军为止。都城告急时优先救援，可以召回在外出征的编队。
- 出征优先选择人口多、守军少、距离近的城市，敌国都城更优先。国家先集中兵力攻打一座城市，兵力足够后再分兵。
- 玩家亲自下令的编队，国家不再调度，命令解除后恢复调度。

### 和平时的部署

- **驻守都城**：一支禁军驻守都城。
- **巡逻边境**：其余人数过半的编队被派往本阵营（本国、宗主、附庸、盟友）与外国接壤的边境，邻国越强、距离都城越近，分到的编队越多。编队在边境各处依次扎营，每处停留半年。本大陆没有外敌时，编队乘船前往海外的边境。
- **换防**：驻守都城满十年后，巡逻最久的编队返回接替，原驻守编队改去巡逻。
- 人数不足一半的编队回到都城补员，补足后再外出巡逻。只有一支禁军时，它驻守都城。
- 军队的悬停提示和军队窗口显示编队当前的任务。

## 地方军

地方军是城主自己的兵。兵制为贵族私兵时，地方军照原版行事：兵力达到兵额的 70% 后进攻最近的敌城。其他兵制下，地方军以防守为主：

- **本城被围**：回城驻守。
- **战时**：前往最近的边境城市驻守。攻下敌城后，该城成为新的驻地。
- **出击**：同一驻地的地方军合计兵力不少于相邻敌城的守军时，一同出击。
- **和平时**：回到本城附近，照原版活动。

## 军械

军械是国家为禁军、各城为地方兵配备的统一制式装备：一件武器，加同一材质的头盔、胸甲和靴子。材质从铜开始逐档提升：铜、青铜、铁、钢、秘银、精金。

| | 禁军 | 地方兵 |
|---|---|---|
| 出资 | 国库，用量按议会的[财政重心](parliament.md#内政) | 本城仓库 |
| 先保留 | 国库的[储备](treasury.md#钱花在哪) | 两年的地方兵军饷和建房的钱 |
| 词条 | 比民间打造的多 | 比民间打造的多，少于禁军 |
| 材料 | 向本国各城收购，不足时向商队购买 | 只用本城仓库的存货 |

- **兵种**：约四分之一为弓手，文化偏好弓的国家一半为弓手。近战兵配发文化偏好的武器：剑、斧、锤或矛。
- **换装**：每年发饷后，装备最差的士兵优先换装。优于制式的装备保持不动。优先使用仓库里可用的旧装备，没有才购买。军队大量补员而资金不足时，先配发较便宜的装备，之后逐年换成制式。
- **升档**：达到现行制式的士兵占编制人数的九成后，次年制式升一档材质。秘银和精金商队不出售，需要本国存货足够全军换装才会升到这两档。
- **武器加成**：国家或城市打造的武器档次越高，士兵伤害加成越大，铜为 +10%，钢为 +50%，精金为 +80%。
- **修理**：国家和城市为自己配发的装备付费修理，和平时期基本不产生费用。
- **回收**：换下的装备回炉后退还部分费用，守城阵亡的士兵留下的装备由城市收回。

王国窗口显示禁军装备，城市窗口显示地方兵装备，均为大部分士兵实际装备的档次，不一定是制式。财政重心为「专供营建」时，禁军不配发装备，照原版自行打造。

## 军饷

禁军和地方兵都需要发饷。发不出军饷时，军队会裁员，战斗力下降，见[国库、军饷与营建](treasury.md#养兵)。

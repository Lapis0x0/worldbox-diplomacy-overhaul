# 指挥军队

原版的军队没有命令可言：城市挑一个进攻目标，队长每做完一件事就随便挑下一件，闲逛、等人、聊天。现在你可以给任何国家的任何军队下令，军队会一直执行，直到你解除命令或者命令失效。解除后，地方军交还原版 AI，禁军交还国家指挥。

## 三种命令

下令时看你点的是什么：

| 点的地方 | 命令 |
|---|---|
| 别国的城市 | **进攻** |
| 本国或友方的城市（宗主、附庸、盟友） | **驻扎** |
| 城外的空地 | **扎营** |
| 这支军队正在驻扎的城或扎营的地方 | **解除命令** |

**进攻**

- 两国没在打仗就先宣战。附庸不能对外宣战；附庸对自己的宗主下手，附庸关系随即解除。
- 不用等兵凑够，下令就出发，士兵放下手头的事跟上队长。
- 目标城市打下来、或者不再是敌人，命令自动解除。
- 读档或游戏重载后，进攻命令会丢失，军队回到原来的行为。

**驻扎**

- 军队开到那座城，在城中心附近待命，有敌人打进城就去迎战。
- 驻扎期间军队不会被调去别处，士兵也不会散去闲逛。
- 驻扎会保存在存档里。城丢了，或者那个国家不再是友方，驻扎自动解除。

**扎营**：和驻扎一样，只是地点在野外。那块地变成水或山时自动解除。

## 怎么下令

### 框选

不拿神力时就能用：

- **缩远地图**：左键拖一个框，框住军队的旗帜。框里有几个国家的军队时，只选军队最多的那个国家的。
- **拉近地图**：用原版的框选选中士兵，就等于选中他们所在的军队。
- 单击一面军队旗帜，也能选中这支军队。
- 选中后**右键**点城市或空地下令，规则见上表。选中的军队都驻扎在你点的地方时，右键就全部解除。
- **Esc** 取消选择。没选中军队时，右键照原版。

### 神力

- **指挥军队**：先点一支军队（旗帜或者附近的士兵），再点目标。
- **举国进攻**：先点一个国家（点它的一座城），再点目标城市。别国的城就让这个国家所有军队一起进攻；本国或友方的城就让所有军队去那里驻扎。
- **交还指挥**：点一个国家，它所有听你命令的军队全部解除命令，交还 AI。拿着这个神力时，地图上会画出这些军队的去向。

## 地图上的提示

- 选好军队后，从军队到鼠标画一条箭头。鼠标下的城市按命令着色：红色是进攻，绿色是驻扎，白色是解除。
- 听你命令的军队，旗帜上显示人数：红色在进攻，绿色在驻扎或扎营。军队的悬停提示和窗口里多一行「命令」。

## 跨海

目标在另一块大陆上时，军队会自动叫船。船从军队附近能出海的港口出发，附近没有空闲的运输船就在港口造一艘。一个港口都没有的国家没法渡海，会提示没有可用的运输船。

## 补员

原版的新兵只有在队长回到本城时才归队，驻扎在外的军队补不了人。现在只要队长在本国任何一座城里、和新兵在同一块大陆，新兵就会自己走过去归队。

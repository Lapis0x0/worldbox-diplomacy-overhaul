# 指挥军队

原版的军队没有命令：城市选定一个进攻目标，队长每完成一件事就随机选择下一件。模组允许玩家给任何国家的任何军队下达命令，军队持续执行，直到命令被解除或失效。命令解除后，地方军交还原版 AI，禁军交还国家指挥。

## 三种命令

命令取决于点击的目标。

| 点击的目标 | 命令 |
|---|---|
| 别国的城市 | **进攻** |
| 本国或友方（宗主、附庸、盟友）的城市 | **驻扎** |
| 城外的空地 | **扎营** |
| 军队正在驻扎的城市，或扎营的地点 | **解除命令** |

**进攻**

- 两国未处于战争状态时，先宣战。附庸不能对外宣战；附庸进攻自己的宗主时，附庸关系随即解除。
- 无需等兵力集齐，下令后立即出发，士兵放下手头的事跟随队长。
- 目标城市被攻下或不再是敌国时，命令自动解除。
- 读档或热重载后，进攻命令丢失，军队恢复原来的行为。

**驻扎**

- 军队前往该城市，在城中心附近待命。有敌人攻入城市时，军队迎战。
- 驻扎期间，军队不会被调往别处，士兵也不会离开。
- 驻扎会保存在存档中。城市丢失或所属国家不再是友方时，驻扎自动解除。

**扎营**：与驻扎相同，地点在野外。该处变为水域或山地时自动解除。

## 下令方式

### 框选

不使用神力时即可操作。

- **缩远地图**：左键拖出方框，选中旗帜在框内的军队。框内有多个国家的军队时，只选军队最多的国家。
- **拉近地图**：用原版的框选选中士兵，即选中其所在的军队。
- 单击军队旗帜，也可选中该军队。
- 选中后**右键**点击城市或空地下令。选中的军队都在点击处驻扎时，右键解除全部命令。
- **Esc** 取消选择。未选中军队时，右键照原版。

### 神力

- **指挥军队**：先点击一支军队（旗帜或附近的士兵），再点击目标。
- **举国进攻**：先点击一个国家（点它的一座城），再点击目标城市。目标是别国的城市时，该国所有军队一同进攻；目标是本国或友方的城市时，所有军队前往驻扎。
- **交还指挥**：点击一个国家，它所有听从玩家命令的军队解除命令，交还 AI。手持该神力时，地图上显示这些军队的去向。

## 地图上的显示

- 选中军队后，从军队到鼠标画出箭头。鼠标所在的城市按命令着色：红色为进攻，绿色为驻扎，白色为解除。
- 听从玩家命令的军队，旗帜上显示人数：红色表示进攻，绿色表示驻扎或扎营。军队的悬停提示和窗口中增加一行「命令」。

## 跨海

目标在另一块大陆时，军队自动调用运输船。船从军队附近可出海的港口出发，附近没有空闲的运输船时在港口建造一艘。国家没有港口时无法渡海，并提示没有可用的运输船。

## 补员

原版中新兵只有在队长回到所属城市时才编入军队。现在队长在本国任一城市、且与新兵在同一块大陆时，新兵即前往编入。

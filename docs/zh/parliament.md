# 议会与政策

议会是国家决定政策的机构，君主国也有议会。各家族（原版的氏族）按占有的城市分得议席，逐项政策投票，决定国家的税收、兵制、分封和外交路线。王国窗口左边的第二个页签是议会；在地图上选中王国时，右下角也有一个议会按钮。

## 议席

- 每座城市给城主所在的家族分配议席，城市越大议席越多，100 人的城市约 20 席。首都的议席归王室，共和国归执政所在的家族。
- 只有一座城的国家，议席全在王室手中。国家扩张后，地方家族的议席合计会超过王室。
- **宗室**：君主国中，王族成员担任边远城市的城主时，这些城市的议席单独计为宗室。靠近首都的王族城市仍属王室。宗室拥护王朝，从不赞成废除君主制，但它不愿交出自己的兵和钱，最希望分封。共和国没有宗室。
- 孩子随承嗣的一方进入家族。祖上三代以内有人担任过国王或城主，就仍属这个家族；一百多年没有人任官，这一支即告没落。

## 立场和派系

每个家族在两条轴上有各自的位置。

- **保守与激进**：老家族、年长或知足、诚实的族长偏保守；新家族、年轻或有野心的族长偏激进。
- **集权与分权**：靠近首都、族长多疑的家族偏集权；远离首都、想自立的家族偏分权。国家的城市越少，离首都远近的影响越小。

新族长上任时只会把家族的立场向自己这边移动一部分。

家族可以带「政见」特质：保守、激进、集权、分权。带有某项特质的家族始终站在该侧，门第和族长只决定它的程度。可以在氏族窗口的特质编辑器中添加。

两条轴划分出四个派系，同一派系的家族颜色相同。

| | 集权 | 分权 |
|---|---|---|
| 保守 | 保王派（蓝）：朝中的老家族 | 贵族派（青）：地方上的老家族 |
| 激进 | 维新派（红）：朝中的新贵 | 共和派（橙）：地方上的新贵 |

共和国中，保王派称元老派，共和派称自治派，颜色不变。

## 政策

政策分内政、军事、外交三页。每项政策的选项排在一条轴上，一端是保守或分权，另一端是激进或集权。附庸政策和附庸贡赋只有带附庸的国家才有，臣属方针只有附庸才有。

### 内政

**国家政体**：君主制或共和制。改为共和制时，现任君主下台，由议会选举执政；改为君主制时，现任执政的家族成为王室。这一项需要四分之三的议席赞成。

**选官制度**：城主空缺时由谁接任。

| 选项 | 接任者 |
|---|---|
| 世袭 | 上一任城主的家族成员 |
| 宗室优先 | 优先从王室成员中选（原版做法）。共和国中称论资排辈 |
| 唯才是举 | 全国最有才干的人，不看出身 |

城主所在的家族决定城市议席的归属，所以选官制度会改变议会格局：世袭使地方家族保住城市，宗室优先使宗室壮大，唯才是举会不断产生新的家族。

**领地制度**：

| 选项 | 效果 |
|---|---|
| 分封制 | 更常把叛乱的城市、攻下的城市分封为附庸，更常分封宗室 |
| 有限分封 | 仅在治理不过来时才分封 |
| 中央直辖 | 很少分封，更常把行省收归直辖 |

**税收体制**：城主上缴收入的比例，详见[国库、军饷与营建](treasury.md)。

| 选项 | 上缴 |
|---|---|
| 包税制 | 25% |
| 分成制 | 50% |
| 统收制 | 75% |

精灵建国时从包税制开始，羊族从统收制开始，其余从分成制开始。原版的「低贡物」「高贡物」特质由这项政策取代。

**财政重心**：国库储备以外的钱，用于禁军装备和[营建](treasury.md#营建)的上限。两项都只在需要时花费，用不完的留在国库。装备详见[军械](armies.md#军械)。

| 选项 | 效果 |
|---|---|
| 专供营建 | 余钱全部用于营建，禁军照原版自行打造装备 |
| 营建优先 | 多数余钱用于营建；为禁军补发缺少的装备，不升级 |
| 均衡拨款 | 营建和军械各占一半；编制人数九成的禁军士兵装备齐全后，升一档材质 |
| 专供军备 | 余钱全部用于禁军装备 |

**教化政策**：

| 选项 | 效果 |
|---|---|
| 因俗而治 | 文化、语言、宗教与首都不同的城市，忠诚度扣减减半 |
| 顺其自然 | 照原版 |
| 同文同教 | 这几项忠诚度扣减加重，但每年有一部分居民改用国家的文化、语言和宗教 |

### 军事

**兵制**：各城市的兵额编入中央[禁军](armies.md)的比例，其余为城主的地方军。都城的兵全部编入禁军。

| 选项 | 各城编入禁军 |
|---|---|
| 贵族私兵 | 不编入，地方军照原版主动出击 |
| 有限义务 | 25% |
| 均衡动员 | 50% |
| 中央军团 | 75% |

**海军方针**：

| 选项 | 每个港口的运输船 | 陆上单位伤害 |
|---|---|---|
| 陆权优先 | 1 艘 | +15% |
| 海陆并重 | 2 艘 | 照常 |
| 海权优先 | 4 艘 | -15% |

运输船配有火炮，会轰击海岸，渡海作战也依靠它。

### 外交

**外交路线**：在[政体倾向](government.md#政体倾向)的基础上调整。

| 选项 | 效果 |
|---|---|
| 和平主义 | 两场战争的间隔加倍，只挑战弱得多的对手 |
| 现实主义 | 照政体倾向 |
| 扩张主义 | 两场战争的间隔减半，敢于挑战比自己强一些的对手 |

**附庸政策**：宗主对所有附庸的政策。

| 选项 | 效果 |
|---|---|
| 自治特许 | 附庸对宗主好感 +15，整合度每年 -1 |
| 封臣契约 | 照常 |
| 强制同化 | 每年将附庸城市中 5% 文化或宗教与宗主不同的居民同化；附庸的文化或宗教与宗主不同时，好感 -30 |

**附庸贡赋**：附庸收入交给宗主的比例。

| 选项 | 交给宗主 | 附庸对宗主的好感 |
|---|---|---|
| 休养生息 | 不交 | +20 |
| 按例纳贡 | 25% | 不变 |
| 加重贡赋 | 50% | -60 |
| 竭泽而渔 | 75% | -100 |

**臣属方针**：附庸自己对宗主的态度。

| 选项 | 效果 |
|---|---|
| 争取自治 | 整合度每年 -1，独立密谋的动机更强 |
| 履行契约 | 照常 |
| 忠诚臣属 | 整合度每年 +1，独立密谋的动机更弱 |

## 政制名称

议会窗口中国名下方的小字是国家的政制名称，由现行政策的组合决定，鼠标悬停可以看到构成它的各项政策。例如世袭、分封制、包税制、贵族私兵的国家称「封建割据」，中央直辖、统收制、同文同教的国家称「专制君主制」，同文同教、中央直辖、分成制或统收制的帝国称「天朝上国」，谋求自治的君主制附庸称「自治领」，共和国附庸称「自治邦」。议会和领袖的称呼也随政制变化，例如三级会议、枢密院、元老院、大议会，以及可汗、盟主、首席元老。

## 表决与提案

- 每个国家每 4 到 6 年召开一次议会，表决一份议案。议案在上一次议会时起草，在议会窗口中可以看到提案的家族和表决的时间。
- **逐项表决**：每个家族对每项政策有自己想要的选项。议案使该政策更接近它想要的选项就赞成，否则反对，按议席计票，过半通过。提案人与自己的好感也影响投票：交好的家族提出的议案，略有不利也可能获得赞成。
- **处境**：家族想要的选项除了立场，还取决于自身处境。港口多的家族倾向海权，内陆家族倾向陆权；治理异族居民的家族倾向因俗而治；兵和钱收归中央对王室有利，对地方家族不利；族长尚武或暴躁的家族倾向扩张，战时各家族都倾向增加军备；宗主所在的家族倾向多收附庸贡赋。
- **集团**：结成[集团](blocs.md)的家族一同投票。
- **提案**：越不满、议席越多的家族越容易成为提案人。提案人提出它最想改变的那项政策，不考虑能否通过。两派对立时议案常被否决，政策推行缓慢。没有家族想改变政策时，该期没有议案。
- **王室的顾虑**：掌权的家族会预估议案是否会引起地方不满。国家鼎盛、地方安稳时，王室倾向收权；国家衰落、地方不稳时，王室不会过度收权。

议案通过后，世界日志记录「某国推行某政策」。设置中的「推行政策提示」关闭时，这条记录只写入世界历史，不在左上角弹出。

## 家族好感

同一议会中的家族之间有好感，各自单向计算。好感来自：

- **政见**：立场相近则好感上升，相左则下降。
- **挚友与联姻**：两家的族长是挚友，或族长的伴侣属于对方家族。
- **邻里**：两家的城市相接壤。
- **恩情**：某家本不想赞成却投了赞成，提案人对它记下恩情；议案使某家受益，它对提案人记下恩情。
- **积怨**：某家投反对使提案人的议案落空，提案人对它记下积怨；议案使某家受损，它对提案人记下积怨。

恩情约十年消退，积怨约二十五年消退。族长更换后，恩情与积怨保留三分之二。王室同样记恩怨，一味削藩的王室与地方家族的关系会不断恶化。

家族窗口的「概览」上方一行列出该家族在议会中交好（左）和交恶（右）的家族，悬停旗帜可以看到双方的好感和明细。

## 地方的不满

政策会影响各家族所占城市的忠诚度（首都和王室的城市除外），明细可在城市窗口查看。

- **政见相合与政见不合**：各项政策都在家族想要的选项上时，城市忠诚度上升；偏离越多，忠诚度越低。强行推行多数家族反对的政策，会使这些家族的城市同时不满。
- **削藩**：兵和钱收归中央的程度超过家族的意愿时，其城市忠诚度下降。兵制和税收都推到最集权时，地方城市容易叛乱。

城市忠诚度下降也会影响[王朝兴衰](cycle.md)。

## 玩家操作

- **提出议案**：在任一政策上点击另一个选项，以它取代现有议案。点击现行选项，撤回这项政策上的议案。
- **表决预测**：鼠标悬停在政策选项上，显示赞成与反对的议席以及能否通过。
- **立即表决**：不等下次议会，立即投票。
- **强行颁布**：不经投票直接生效，反对的家族的城市会不满。
- **撤回**：撤下现有议案，无论由谁提出。
- **写入宪章**：展开某项政策，点击所选选项右端的锁，政策名后会出现「宪章」标记。此后议会不再提议修改这项政策，但家族仍会因它不满。在自己提出的议案上点击锁，则直接颁布并写入宪章。选择其他选项后，该政策移出宪章。

议会窗口左边是议席半圆、家族列表和标出各家族立场的坐标图，王室的点戴有皇冠，宗室在列表中紧随王室。集团的显示见[集团](blocs.md)。右边是各项政策和当前议案。

在设置中关闭「议会与政策」后，各项政策不再生效，城主的上缴恢复为原版的贡赋特质，附庸不再上贡，家族也不会因政策而不满。共和国仍照常选举执政。

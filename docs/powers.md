# 神力与设置

所有神力都在底部「外交大修」Tab 里，从左到右分四组：设置 | 附庸 | 战争 | 城镇管理。需要点两下的神力，选第一个目标后会在地图上画箭头、高亮区域；第二下点回第一个目标就取消。

## 附庸

| 神力 | 用法 | 效果 |
|---|---|---|
| 册封附庸 | 先点宗主，再点附庸 | 后者成为前者的附庸。宗主是附庸、或附庸有自己的附庸时不行 |
| 煽动独立 | 点一个附庸 | 它立即向宗主发动独立战争 |
| 大叛乱 | 点一个国家 | 立即爆发大叛乱，不看周期阶段 |
| 天命 | 点一个大国 | 王朝周期推进一个阶段；衰落期再推就是大叛乱 |
| 分封附庸 | 点一座非首都城市 | 它自立为国，成为原国家的附庸 |

规则见[附庸](vassals.md)和[王朝周期与大叛乱](cycle.md)。

## 战争

| 神力 | 用法 | 效果 |
|---|---|---|
| 指挥军队 | 先点一支军队，再点目标 | 别国城市进攻，友方城市驻扎，空地扎营，点驻地解除 |
| 举国进攻 | 先点出兵的王国，再点目标城市 | 所有军队进攻别国城市，或全军前往友方城市驻扎 |

不拿神力时也可以框选军队、右键下令。规则见[战争与军队](military.md)。

## 城镇管理

| 神力 | 用法 | 效果 |
|---|---|---|
| 移交城市 | 先点一座城，再点接收的王国 | 城市归接收方。首都不能移交 |
| 吞并王国 | 先点吞并方，再点被吞并方 | 被吞并方的城市全部归吞并方，它的附庸转给吞并方；吞并方本身是附庸时，这些附庸获得自由 |

两者都会立即更新双方的政体称号。

## 设置

点 Tab 最左边的设置按钮打开。改 `default_config.json` 里的设置项（新增、删除）要重启游戏才生效，调数值不用。

| 分组 | 设置 | 默认 | 范围 |
|---|---|---|---|
| 附庸 | 附庸对宗主的好感加成 | 30 | 0–200 |
| | 好感低于此值时开始心生怨恨 | 0 | -200–100 |
| | 宗主实力低于附庸的百分之多少时视为衰落 | 120 | 50–300 |
| | 大国会分封城市，弱小邻国会俯首称臣 | 开 | |
| 投降 | 启用战败投降成为附庸 | 开 | |
| | 开战至少多少年后才可能投降 | 5 | 1–50 |
| | 丢失城市达到开战时的百分之多少 | 50 | 10–90 |
| | 胜方实力达到败方的百分之多少 | 200 | 100–500 |
| 政体 | 随国力和附庸状态自动更新政体 | 开 | |
| | 国名后面显示政体 | 开 | |
| | 政体随历史事件改变 | 开 | |
| 王朝周期 | 大国经历新生、鼎盛、衰落、崩溃的王朝周期 | 开 | |
| | 中兴密谋成功的概率（百分比） | 30 | 0–100 |
| 性能 | 优化原版的重复计算，让游戏更流畅，不改变游戏结果 | 开 | |

# 议会与政策

每个国家都有一个议会。各氏族按占据的城市分得议席，按自己的立场对议案投票，议案改变国家的政策。所有政体都走同一套议会，平民不算政治力量。

## 议席

- 每座城给它城主所在的氏族 `round(2 × √城市人口)` 席，首都归国王（共和国是执政）的氏族。原版城主、国王上任时没有氏族会自动建一个，所以每座城都有归属。
- 国家的议席总数是各城之和，不设上限和下限：普通城（100 人）20 席，3 座城约 90 席，十几座城的帝国两三百席。
- 一座城的国家议席全在王室手里；占城越多、城越大，氏族的议席越多，帝国扩张后地方氏族的议席会超过王室。

## 氏族立场

每个氏族在两条轴上有一个位置，都在 -1 到 +1 之间。门第和离首都的远近都和同一个议会里的其他氏族比，世界过了多少年都分得出来。

**保守（-）到激进（+）**：

| 项 | 计算 |
|---|---|
| 门第 | 家族年龄取对数，和议会里各家族的平均比：老 4 倍及以上 -0.3，新 4 倍及以上 +0.3，中间连续变化。刚建的家族按 10 年算 |
| 王室 | 君主国的王室再 -0.2；共和国的执政家族不算 |
| 性格 | 野心勃勃 +0.4，暴躁 +0.25，知足 -0.4，诚实 -0.2；族长占一半，族人（最多 50 人）的平均值占一半 |
| 族长的年龄 | 35 岁不偏，越老越保守：15 岁 +0.1，75 岁 -0.2（已经乘上族长的一半） |
| 家风 | 按氏族固定的一点偏向，-0.2 到 +0.2 |

**分权（-）到集权（+）**：

| 项 | 计算 |
|---|---|
| 离首都的远近 | 氏族占的城离首都的平均距离，和国内离首都最远的城比：在首都 +0.3，和最远的城一样远 -0.3 |
| 王室 | 王室（共和国是执政家族）再 +0.2 |
| 受提拔 | 占的城里城主按唯才是举任命的比例，全是最多 +0.2 |
| 家风 | -0.2 到 +0.2 |

## 派系

四个象限各是一个派系，同派系的氏族用同一种颜色：

| | 集权 | 分权 |
|---|---|---|
| 保守 | 保王派（蓝）：朝中的老家族 | 贵族派（青）：地方上的老家族 |
| 激进 | 维新派（红）：朝中的新贵 | 共和派（橙）：地方上的新贵 |

## 政策

政策分在内政、军事、外交三个页签。附庸政策只在有附庸时出现，臣属方针只在自己是附庸时出现；附庸没有领地制度和外交路线（附庸不分封、不自己开战）。

### 内政

**税收体制**（分权 → 集权）：城主把收入的多少上缴国王。

| 选项 | 上缴 |
|---|---|
| 包税制 | 20% |
| 分成制 | 50% |
| 统收制 | 70% |

原版的「低贡物」「高贡物」王国特质不再出现在特质编辑器里，上缴比例只由税收体制决定。原版精灵默认低贡物、羊族默认高贡物，这两个物种建国时分别从包税制、统收制开始，其余从分成制开始；旧存档里国家身上的贡赋特质也按同样的规则换成政策。原版的地方税率（居民交给城主）不变。

**领地制度**（分权 → 集权）：

| 选项 | 效果 |
|---|---|
| 分封制 | 叛乱改分封、攻城改分封的概率 ×1.5；分封宗室的动机 ×2；收归直辖的动机 ×0.5 |
| 有限分封 | 照[附庸](vassals.md#分封)的规则 |
| 中央直辖 | 叛乱改分封、攻城改分封的概率 ×0.5；分封宗室的动机 ×0.5；收归直辖的动机 ×2 |

设置里关掉分封时，三个选项都不分封。

**选官制度**（保守 → 激进）：城主空缺时由谁接任。

| 选项 | 接任的人 |
|---|---|
| 世袭 | 上一任城主的家族里挑，挑法照原版（按年龄和文化的继承特质）；这个家族在国内没人了再照原版 |
| 宗室优先 | 原版：先从全国的王室成员里挑，没有再从其他家族里挑最年长的。共和国没有王室，这一档叫论资排辈 |
| 唯才是举 | 全国成年人里管理加智力最高的，不看家族，一样高时挑年长的 |

城主的家族就是这座城的议席归属，所以选官制度会改变议会的格局：世袭让地方家族守住自己的城，宗室优先让王室越占越多，唯才是举提拔出的人原来多半没有家族，上任后原版给他新建一个，成为议会里的新贵。原版城主和国王同一家族时城市忠诚 +30，不同时 -20，非王室的城主越多，忠诚越低。

**教化政策**（分权 → 集权）：

| 选项 | 效果 |
|---|---|
| 因俗而治 | 原版忠诚里文化、语言、宗教和首都不同的扣分减半 |
| 顺其自然 | 不变 |
| 同文同教 | 这三项扣分 ×1.5；每年国内每座城里 10% 文化、宗教或语言和国家不同的居民，改用国家的文化、宗教和语言 |

原版三项扣分是文化 -25、语言 -20、宗教 -30，相同时各 +15 不变。城市的文化、语言、宗教跟城主走，城主被同化后城市跟着变。

**国家政体**（保守 → 激进）：君主制或共和制，就是[政体](government.md)的大类。

- 改共和制：撤销王室，现任君主下台，按共和国的规则推举执政。
- 改君主制：现任执政的家族成为王室。
- 这一项要 3/4 的议席赞成才通过。手动锁定政体的国家和行省不能对它提案。

### 军事

**兵制**（分权 → 集权）：领主私兵、双轨兵制、中央常备军。要等中央军（WORLD-26），现在灰着，不能提案，也不算进国家坐标。

**海军方针**（保守 → 激进）：每个港口最多有几艘运输船。运输船带炮，会轰海岸，渡海作战也靠它。

| 选项 | 每个港口的运输船 |
|---|---|
| 陆权优先 | 不再新造 |
| 海陆并重 | 1 艘（原版） |
| 海权优先 | 3 艘 |

造船照原版花资源。政策改小时已有的船不会被拆，坏了不再补。玩家指挥军队渡海时临时调的船不受这个上限限制，见[战争与军队](military.md#跨海)。

### 外交

**外交路线**（保守 → 激进）：乘在[政体倾向](government.md#政体倾向)的数值上。

| 选项 | 停战期 | 敢挑的对手 |
|---|---|---|
| 和平主义 | ×2 | ×0.5 |
| 现实主义 | 不变 | 不变 |
| 扩张主义 | ×0.5 | ×1.25 |

**附庸政策**（分权 → 集权）：宗主的政策，对它所有的附庸生效。

| 选项 | 效果 |
|---|---|
| 自治特许 | 附庸对宗主好感 +15（「自治特许」）；附庸整合度每年 -1 |
| 封臣契约 | 不变 |
| 强制同化 | 每年附庸每座城里 10% 文化或宗教和宗主不同的居民，改为宗主国家的文化和宗教；附庸国家的文化或宗教和宗主不同时，对宗主好感 -20（「强制同化」） |

原版城市的文化跟城主走，国家的文化跟国王走，所以同化只转化居民，城主、国王转化后城市、附庸跟着变。同一文化、同一宗教各让整合度每年 +1，同化完成后附庸归化得更快。

**臣属方针**（分权 → 集权）：附庸自己的政策。

| 选项 | 效果 |
|---|---|
| 争取自治 | 整合度每年 -1；独立密谋的动机 ×1.5 |
| 履行契约 | 不变 |
| 忠诚臣属 | 整合度每年 +1；独立密谋的动机 ×0.5 |

## 表决

- **国家坐标**：每项政策的选项依次排在它那条轴上（三个选项是 -1、0、+1，两个选项是 -1、+1），国家坐标是各项现行政策在两条轴上分别取平均。只算这个国家看得到的政策。
- **投票**：每个氏族比较议案通过前后国家坐标离自己的远近（两轴的直线距离），近了赞成，远了反对。票数按议席算，赞成超过一半通过，国家政体要超过 3/4。
- **改政体的切身利益**：表决国家政体时，再按氏族的利益把通过后的距离加减 0.25。改君主制时执政家族会成为王室（-0.25），其他氏族要受人统治（+0.25）；改共和制时王室失去王位（+0.25），其他氏族有机会轮流执政（-0.25）。提案人挑议案时也这样算。其他政策只看立场。

## 议会周期

- 每个国家每 4 到 6 年开一次议会，间隔随机。新国家（和装模组前的旧国家）第一次在 1 到 6 年内，先起草一个议案。
- 开议会时表决现有的议案；没有议案（被撤回、或已经不成立）就当场起草一个再表决。之后起草下一期的议案，在王国的议会窗口里能看到。
- **起草**：按议席抽一位提案人，议席越多越容易抽中。提案人试遍所有能提的政策和选项，挑让国家坐标离自己立场最近的一项；几项一样好时随机挑。改动后离自己的立场近不到 0.1，就算满意，这一期没有议案。
- 议案通过时世界日志记一条「某国推行某政策」。

## 玩家干预

王国窗口左侧页签栏第二个是议会，点开是单独的议会窗口。在地图上选中王国时，右下角也有一个议会按钮，和左下角原版的王国图标、取消按钮对称，一起出现和收起。议会窗口左边照样有这一栏页签，点别的页签回到王国窗口的那一页。屏幕窄、放不下整个窗口时，窗口整体缩小，并让开左边原版的工具栏。

议会只有一份议案。鼠标悬停在政策选项上，提示里有议会对这一档的表决预测（赞成和反对的席位、能不能通过）。

- 在任意政策上点一个别的选项，就提出议案，取代原来的议案；顶替了某个氏族的议案时屏幕上方提示一句。点现行选项撤回这项政策上的议案。
- **立即表决**：不等下次议会，现在就按议席投票，通过就生效，不论结果议案都撤下。
- **强行颁布**：不投票，直接生效。
- **撤回**：撤下议案，不论是谁提的。

## 界面

- 左边：议席半圆按派系从激进（左）到保守（右）排开，中间写最大派系和它的席位；一、两座城的国家不画半圆，写「某某家独掌朝政」或「某某家主导朝政」。氏族列表王室或执政家族在最上面；点列表里的氏族或半圆里它的议席都能选中它：列表滚到它那一行，半圆和坐标图里其他氏族变淡，下方显示族长和占的城。坐标图上王室的点戴皇冠。
- 右边：政策按页签分开，每项一行显示现行选项（红底；还没有效果的政策灰底，不能点开），点开显示所有选项。鼠标悬停在选项上有一句说明，下面列出这一档的数字（上缴比例、每港运输船，其余只列偏离照常的倍数和每年变动），数字和效果用的是同一组常量；展开后议案的选项带黄框。下方是议案：哪个氏族提的（玩家提的不写）、几年后表决、赞成反对的横条（白线是通过线）和各氏族的票。

原版挂点：

- `Kingdom.getTaxRateTribute`：上缴比例按税收体制。
- `TooltipLibrary.showTip`：政策选项的提示里加上数字行。
- 领地制度乘在 `Feudal` 的叛乱、攻城分封概率上，并改 `Appanage`、`DirectRule` 的条件和动机。
- `CityBehCheckLeader.checkFindLeader`：选官制度在原版挑城主之前先挑，宗室优先或没挑到人时照原版。
- 原版忠诚 `culture`、`language`、`religion` 三项换成照抄原版再乘教化政策倍数的版本。
- 外交路线乘在 `Government.WarTimeout`、`Government.WarStrengthRatio` 上。
- `Docks.isFull`、`Docks.isOverfilled`、`Docks.buildBoatFromHere`：运输船的上限按海军方针；超额只按最高的 3 艘算。
- 附庸政策、臣属方针改 `Integration` 的每年变动和 `Core` 的独立动机。
- `KingdomWindow.showStatsRows`：给王国窗口左侧页签栏加上议会。
- `PowerButtonSelector.updateSelectedUnitCancelButton`：左下角的选中取消按钮显示或收起时，右下角的议会按钮跟着。

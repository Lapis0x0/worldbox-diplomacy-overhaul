# 政体

## 政体一览

每个国家有一个政体大类，**君主制**或**共和国**。显示出来的政体是一个王国特质（特质组「政体」），由大类、城市数、附庸状态决定：

| 大类 | 显示 | 条件 |
|---|---|---|
| 君主制 | 王国 | 5 座城及以下 |
| | 帝国 | 6 座城及以上 |
| 共和国 | 军事共和国 | 由将领夺权建立 |
| | 商人共和国 | 国家文化有「黄金法则」 |
| | 共和国 | 其余 |
| 附庸 | 公国 | 原本是君主制 |
| | 自治领 | 原本是共和国 |

成为附庸不改变大类，只改变称号，独立后自动恢复。称号每年更新一次，成为附庸、获得独立、移交城市、吞并王国时立即更新。

国名后面接上政体，比如「科英布拉公国」，英文是「Duchy of Coimbra」，可以在设置里关掉。王国窗口和鼠标悬停提示的副标题显示政体，附庸接上宗主名（「公国 · 卡斯蒂利亚」），有王朝周期的接上阶段（「帝国 · 鼎盛」）。

### 手动设置

在原版特质编辑器里给国家换一个政体特质，这个国家的称号就锁定，不再自动更新，也不会发生王室绝嗣改制、称帝、夺权。选了共和国一类的特质，大类变成共和国；选王国或帝国，大类变成君主制。删掉政体特质就交还自动判定。

## 国家诞生时的政体

国家第一次被判定政体时掷一次大类。旧存档里已有的国家也这样补掷。

原版一局里文化很少：文化只在没有文化的人建立第一座城时产生，新生儿和叛乱、分裂出来的国家都沿用原来的文化。所以文化只改变概率，同一个文化下的国家各掷各的。

| 国家文化的继承特质 | 是共和国的概率 |
|---|---|
| 外交晋升、黄金法则 | 50% |
| 名望之冠 | 25% |
| 其他 | 10% |

之后大类只由下面的历史事件改变，不随文化变化。

## 共和国执政

共和国没有王室。

- **推举**：没有执政时，从各城城主里推举一位，按原版挑领袖的方式打分。上一任执政的家族排在最后，只有所有城主都出自这个家族时才会让它连任。被推举的人离开城主之位、搬进首都。世界日志记一条。
- **任期**：12 年。任期满了就卸任，重新推举；找不到别的人选时连任。执政不是推举上来的（比如玩家用神力换了人），从他上任时开始算任期。
- **没有王室**：共和国的执政不会让自己的家族成为王室，城主也就不会偏向某个家族。
- **不会因绝嗣分裂**：共和国遇到原版的绝嗣分裂时，一律重新推举。

推举和任期是共和国本身的规则，关掉「政体随历史事件改变」也照常运行。

## 历史事件

开关「政体随历史事件改变」，默认打开。手动锁定政体的国家不参与。

### 王室绝嗣：君主国改制为共和国

原版里王室家族死绝、又找不到继承人时，多城国家会分崩离析，每个城主各自建国。现在君主国在这一刻有一定概率改由城主们推举执政，改制为共和国，国家保住不分裂：

| 国家文化 | 改制概率 |
|---|---|
| 外交晋升、黄金法则 | 80% |
| 其他 | 40% |

没有改制的照原版分裂。世界日志记一条。

### 共和国称帝

条件：共和国、6 座城以上、不是附庸、处在王朝周期的鼎盛期。每年判定一次，概率是 0.5% 乘以执政的性格权重：

| 执政的特质 | 权重 |
|---|---|
| 基础 | 1 |
| 野心勃勃 | +3 |
| 嗜血、邪恶 | 各 +2 |
| 暴躁、偏执、弑君者、老兵 | 各 +1 |
| 知足、诚实、和平主义、温和（任意一个） | 权重为 0，不会称帝 |

鼎盛期平均约 70 年，算下来普通执政（权重 1）的共和国约 30% 会在鼎盛期称帝，执政野心勃勃（权重 4）时约 76%。

称帝后大类变成君主制，执政的家族成为王室（他没有家族就新建一个），国家显示为帝国。世界日志记一条。

### 乱世夺权

条件：国家处在王朝周期的崩溃期。每年有 10% 的概率发生，文化有「勇者晋升」的是 20%。

夺权的是国内杀敌最多的队长或士兵（国王除外）。结果看他的性格：

- **有野心**（野心勃勃、嗜血、邪恶、暴躁、偏执其中之一）：废掉原来的君主，自立为王，建立新王朝。大类变成君主制，他的家族成为王室（没有家族就新建一个），王朝周期回到新生。
- **没有野心**：将领们夺取政权，成立军事共和国，由他执政，之后按共和国的规则推举、换届。已经是军事共和国的，没有野心的将领不会再起事。

世界日志各记一条。

## 实现

| 文件 | 内容 |
|---|---|
| `Government.cs` | 政体特质组、掷大类、称号判定、手动锁定、国名和标题显示 |
| `Regime.cs` | 共和国推举和任期、王室绝嗣、称帝、夺权 |

`kingdom.data` 里的键：

| 键 | 含义 |
|---|---|
| `vd_gov_form` | 大类：0 君主制，1 共和国 |
| `vd_gov_military` | 共和国由将领夺权建立 |
| `vd_gov_auto` | 最近一次自动设置的政体特质，用来发现玩家手动改过 |
| `vd_gov_locked` | 玩家手动锁定 |
| `vd_gov_term_start`、`vd_gov_term_ruler` | 当前执政的上任年份和 id |
| `vd_gov_last_clan` | 上一任执政的家族 |

原版挂点：

- `KingdomBehCheckKing.execute`：共和国没有执政时由模组推举，不走原版的王室继承。
- `KingdomBehCheckKing.checkKingdomChaos`：原版绝嗣分裂的入口，在这里改制或重新推举。
- `Kingdom.trySetRoyalClan`：共和国跳过，不立王室。
- `TooltipLibrary.showKingdom`、`KingdomWindow.showStatsRows`、`NameplateText`：国名和副标题。

旧版的「城邦」已经取消，存档里的城邦特质在下一次判定时换掉。

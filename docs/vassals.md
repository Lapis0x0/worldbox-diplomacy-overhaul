# 附庸

## 关系

附庸关系只记在附庸国一方：`kingdom.data` 的 `vd_overlord_id` 存宗主的 id。宗主灭亡时它的附庸全部自由；宗主 id 失效时下次读取就清掉。

**不允许附庸链**：宗主自己不能是附庸，有附庸的国家不能成为别人的附庸。

成为附庸的那一刻：

1. 两国之间的战争结束。两国是同一场战争的主攻方和主守方时，这场战争以和平结束；否则附庸退出那场战争。
2. 附庸退出原来的联盟。
3. 更新政体称号（君主制变公国，共和国变自治领，见[政体](government.md)）。
4. 附庸的战争状态和宗主对齐（见下文）。

## 集团

宗主和它的所有附庸算一个**集团**。

- 原版 AI 挑战争目标、挑结盟对象时，跳过同集团的国家。
- 附庸不会自己发动战争，不能发起结盟、加入联盟，也不会被选为结盟对象。
- 王国窗口显示「宗主」或「附庸」一栏，标题写成「政体 · 宗主名」。
- 王国地图上，附庸的边界线用宗主的颜色，填充保持自己的颜色。
- 联盟地图按阵营显示：附庸归入宗主的阵营，宗主有联盟时阵营是联盟，否则是宗主国。染色、名牌、悬停高亮、悬停提示和点击都按阵营；附庸不单独显示名牌，联盟名牌挂在视野内最强的成员或附庸首都上。

### 战争同进同退

- 宗主加入一场战争的防守方，它的附庸全部加入防守方。宗主加入攻方时，每个附庸按整合度的百分比概率参战（最低 30%，行省一定参战），每场战争只掷一次。
- 附庸被攻击，宗主加入防守方。
- 宗主退出一场战争（议和、战败），附庸以同样的方式退出。
- 附庸只参加宗主参加的战争：大约每个游戏月同步一次，附庸不在宗主那一边的战争会被移出，宗主的战争按上面的规则补进去。
- 总体战不受以上规则约束。

**背叛**：宗主和附庸出现在同一场战争的对立两边（神力宣战、玩家下令进攻自己的集团），附庸关系立即解除。

## 整合度与行省

每个附庸有一个 0–100 的整合度，表示它在自立和归化之间的位置。涨到 90 成为**行省**，跌到 50 以下退回自治领。成为和不再是行省时，世界日志各记一条。

整合度不显示数字，所在的档次显示为一个王国特质（特质组「整合度」），只有附庸有：

| 整合度 | 特质 |
|---|---|
| 0–30 | 积怨 |
| 30–50 | 离心 |
| 50–90 | 归附 |
| 90–100 | 一体 |

鼠标悬停在这个特质上，提示里显示整合度的具体数字。在特质编辑器里换成另一档，整合度就设到那一档的中间值（15、40、70、95），之后照常变动。

### 起点

| 成为附庸的途径 | 起点 |
|---|---|
| 分封（叛乱改分封、攻城改分封、分封宗室、神力分封附庸） | 70 |
| 威逼称臣、神力册封附庸 | 35 |
| 投降、独立战争失败重新成为附庸 | 0 |

附庸随被吞并的宗主转给吞并方时，整合度不变。装模组前就有的附庸从 35 开始。

### 每年的变动

宗主的周期阶段决定方向，两国的结构因素决定快慢：

| 因素 | 每年 |
|---|---|
| 宗主处在新生或鼎盛 | +1 |
| 宗主没有周期 | 0 |
| 宗主处在衰落 / 崩溃 | -3 / -4 |
| 和宗主的城市接壤 | +1；不接壤 -1 |
| 和宗主同一个文化 | +1 |
| 和宗主不是同一个物种 | -1 |
| 两国国王出自同一家族 | +1 |
| 城市数达到宗主的一半以上 | -1 |

整合度低于 30 时，上升的速度减半。

宗主一方赢下一场战争，参战的附庸 +5；宗主一方战败，它的所有附庸 -5。议和不变。

盛世里接壤、同文化的附庸每年 +3：分封的约 7 年成为行省，威逼称臣的约 18 年，投降的约 40 年。宗主衰落时，这样的行省每年 -1，隔海、异族的每年 -5。

### 行省

- 称号是「行省」，不分原来的政体，比如「科英布拉行省 · 卡斯蒂利亚」。
- 成为行省时政体大类改为共和国，按共和国的规则从城主里推举执政、12 年任期，不立王室。在位的君主从这时开始算任期。
- 退回附庸时显示为自治领；独立后是共和国。
- 手动锁定政体的国家可以成为行省，但大类和称号不变。

## 好感

附庸对宗主有两条好感修正，在原版好感明细里能看到：

- **效忠宗主**：+30（设置项）。
- **宗主国运**：看宗主的王朝周期，新生 +10，鼎盛 +20，衰落从 -10 起每年再 -3，最低 -90。

## 成为附庸的途径

### 投降

每场战争每年检查一次（总体战除外），双方的主攻方、主守方都可能投降：

- 开战至少 5 年（设置项）。
- 一方丢掉的城市达到开战时城市数的 50%（设置项）。开战时的城市数在战争开始时记下；装模组前就开始的战争从第一次检查时开始记。
- 胜方的实力达到败方的 200%（设置项）。实力沿用原版公式：战士数 × 2 + 城市数 × 5 + 1。
- 败方不能向自己的附庸投降。

投降后：败方原有的附庸全部独立，战争以胜方获胜结束，败方成为胜方的附庸；胜方本身是附庸时，败方成为胜方宗主的附庸。世界日志记一条。

### 分封

开关在设置里（默认打开）。宗主自己是附庸时不会分封。

**叛乱改分封**：原版里密谋叛乱成功，城主会带着城市自立并开战。现在宗主有一定概率把这座城分封出去，换来附庸而不是敌人：

| 宗主的周期阶段 | 分封概率 |
|---|---|
| 鼎盛 | 80% |
| 没有周期或新生 | 50% |
| 衰落 | 20% |
| 崩溃 | 0 |

首都和与首都相邻的城市不会被分封。分封出去的国家由发起密谋的人统治，参与密谋的其他城市（首都除外）一起归入新国家。

**攻城改分封**：攻下一座城、正要并入时，如果攻方已经达到原版的治理城市上限，有 75% 的概率不并入而是分封出去：

- 附近已有不到 5 座城的附庸（这座城挨着它的首都，或挨着一座挨着首都的城）：直接并给那个附庸。
- 否则城里第一个成年、不是国王的居民建国，成为攻方的附庸。
- 附庸随宗主出征打下的城：和附庸领土接壤就照原版归附庸；隔着别国的飞地按宗主打下的城处理。
- 攻下的是同集团的城不会分封。
- 军事共和国攻下的城不分封，照原版并入。

### 威逼称臣

强国的国王可以发起「威逼称臣」密谋（等级至少 4，花费 30 金币，王国声望至少 50，需要外交能力），遣使威逼一个接壤的弱小邻国。国王有多想发起，看实力差距和他的性格，见[密谋与动机](plots.md)；玩家可以在原版的密谋编辑器里让国王强制发起。

发起条件：

- 强国不是附庸，不处在衰落或崩溃期。设置里关掉分封时这个密谋也一起关掉。
- 至少有一个接壤的邻国愿意称臣：不是附庸，也没有附庸；没在和强国打仗；强国的实力至少是它的 3 倍（帝国是 2 倍）；它对强国的好感不低于 0。

有多个邻国满足条件时，选离得最近的那个。密谋期间条件一直要成立，否则密谋中止。密谋完成后对方成为附庸，世界日志记一条。

### 分封宗室

君主国的国王可以发起「分封宗室」密谋（等级至少 4，金币至少 30）。条件：

- 国家不是附庸，是君主制，城市数超过原版的治理上限。设置里关掉分封时这个密谋也一起关掉。
- 国王家族里有成年、不是国王、住在本国的成员，国王的子女优先。

超出上限越多越想发起，治理型的国王更积极，见[密谋与动机](plots.md)。

密谋完成后，离首都最远的城和与它相连的城（由远及近，超出几座分几座，最多 3 座；首都和与首都相邻的城不分）归这位宗室，他当国王，新国家是君主制、成为附庸，整合度从 70 开始。世界日志记一条。

### 神力

- **册封附庸**：先点宗主，再点附庸。
- **分封附庸**：点一座非首都城市，它自立为国、成为原国家的附庸。国家至少要有两座城；城主当国王，没有城主就随机一个居民；原国家本身是附庸时，新国家成为原国家宗主的附庸。

## 独立

### 独立密谋

附庸的国王可以发起「独立密谋」（等级至少 3，花费 20 金币，需要外交能力），玩家也可以在密谋编辑器里让附庸的国王强制发起。条件：

- 宗主处在衰落期，或者宗主实力低于附庸实力的 120%（设置项）乘以 `1 - 整合度/200`：整合度 0 时是 120%，行省大约是 60%。

附庸有多想发起，看它对宗主的怨恨和国王的性格：好感低于 0（设置项）才开始怨恨，越低越想反，整合度越低越记恨，见[密谋与动机](plots.md)。

密谋成功后，附庸脱离宗主，向它发动一场普通战争（独立战争）。宣战失败时恢复附庸关系。

### 独立战争的结局

独立战争结束时：宗主一方获胜，叛乱方重新成为附庸（宗主已经成了别人的附庸、或叛乱方有了自己的附庸时除外）；其他结局，叛乱方彻底独立。

神力**煽动独立**直接让附庸发动独立战争，结局规则相同。大叛乱也会让附庸按整合度的概率发动独立战争，见[王朝周期与大叛乱](cycle.md)。
